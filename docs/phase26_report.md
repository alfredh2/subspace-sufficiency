# Phase 2.6 report — position-restricted value patching of the frozen S8 heads (exploratory)

**Standing.** New preregistered exploratory experiment (`docs/phase26_plan.md`, committed before implementation). The Phase 2 verdict (**mixed / inconclusive**), the recorded failed original recompute gate, the frozen S8 set, all earlier results and checkpoints are unchanged. Outputs: `results/phase26/` (`position_patching.json`, `report_tables.md`, `criteria_verdict.json`, raw per-trial arrays). GPU budget ≈ **0.41 h of the 0.5 h cap** (first attempt ≈ 8 min was lost to a post-processing bug and rerun; see §5). The head → MLP mediation study was not started.

## 1. Result in one line
**Preregistered localization criteria are met in both numeric formats:** for S8, patching the value vectors only at the **conclusion's final token + generation-prompt tail (G1∪G2, 9 of ≈ 87 positions)** reproduces **0.900 / 0.915** of the all-position V-only transfer into the answer-position head outputs (`num_orig` / `num_rev`), while the remaining positions (including the query token) reproduce ≈ 0 (−0.005 / −0.018) and 10 count-matched random position sets reproduce ≤ 0.006. Neither summary group is sufficient alone (G1 ≈ 0.26–0.28, G2 ≈ 0.31–0.32): their joint effect exceeds the sum.

## 2. Validation and implementation checks (all passed)

* **Full mask reproduces the existing V-only patch:** S8 All-condition transfer equals the stored Phase 2.5 values exactly (0.8884 / 0.7108 `num_orig` all/last rows; 0.8857 / 0.6656 `num_rev`; difference 0.0). Empty mask = no intervention; padding-only masks inert; wrong mask shape raises (tiny-model tests; 91 tests pass).
* **Group assignment:** in all 434 trials per format the groups satisfy the assertions (G1, G2, Self pairwise disjoint; G1∪G2 and Remaining partition the eligible positions; Self ⊂ Remaining; no padding); mean sizes G1 = 1, G2 = 8, Self = 1, Remaining = 78.4 (incl. Self; 77.4 without), All = 87.4. 0 pairs rejected for invalid or mismatched masks (231 of the 448 matched pairs are rejected upstream by the Phase 2.5 alignment rule, leaving 217 pairs). T(All) − T(G1∪G2) − T(Remaining) = +0.075 / +0.068 (the small residual of All over its parts).

## 4. Secondary and descriptive results
* **All query rows (secondary):** F(G1∪G2) = 0.766 [0.748, 0.783] / 0.752 [0.733, 0.770]; **Remaining F = 0.391 [0.368, 0.415] / 0.410 [0.385, 0.436]** (Remaining excl. Self 0.458 / 0.467); random matched to G1∪G2 mean F 0.035 / 0.038 (max 0.042 / 0.044). So when the head outputs at *earlier query rows* are also recomputed with source values at other positions, those other positions contribute substantially — they act via head outputs at other query positions and the downstream computation, not by supplying the answer-position head output directly. The localization claim therefore applies to the *answer-position retrieval*, not to the whole network effect of the heads' value content. Interaction T(All) − T(G1∪G2) − T(Remaining) = −0.139 / −0.144 (sub-additive).
* **Individual heads (primary setting):** L22H5 alone: T(All) = 0.377 / 0.340, F(G1∪G2) = 0.86 / 0.89, F(Remaining) = 0.04 / 0.03, F(G1) = 0.32 / 0.37, F(G2) = 0.28 / 0.30 (localized in the same way). The other seven heads have T(All) < 0.20 individually (L21H19 +0.065/+0.057, L20H8 +0.025/+0.024, L22H15 +0.016/+0.014, L19H10 +0.007/+0.006, L22H4 +0.007/+0.005; **negative contributors** L22H8 −0.030/−0.027 and L22H6 −0.008/−0.005), so F is undefined by the preregistered rule for them; their T(G1∪G2) nevertheless tracks T(All) (e.g. L21H19 0.061 vs 0.065; L20H8 0.025 vs 0.025; L22H8 −0.001 vs −0.030). The sum of the eight individual T(All) is 0.46 vs 0.711 for S8 jointly — again, effects do not add after downstream recomputation.
* **Same-label lexical controls (S8, 732 aligned trials, 68 rejected):** replacing values with those of a *same-label, different-content* example changes the verdict in 4.6 % (G1∪G2, last row; mean |Δ margin| 2.0, max 16.8), 0.5 % (Remaining, last row) and 5.1 % (All, last row) of trials — versus 63–67 % flips for the opposite-label G1∪G2 patch. Lexical content at the summary positions therefore produces a small but nonzero verdict effect (≈ 5 %), comparable to the Phase 2 lexical control (6 %).

## 5. Deviations and failures (all reported)
* The first full run (≈ 8 min GPU) crashed in post-processing (a misplaced conditional evaluated the random-control summary for single-head sets) before saving results; the script was fixed, raw per-trial arrays are now saved immediately after each pass, and the experiment was rerun in full with the run-time abort set to 21 min so that the total stayed inside the 0.5-h cap (total ≈ 0.41 h). No result from the discarded run was used or inspected beyond the validation lines printed before the crash (which agree with the rerun).
* F is undefined (not evaluable) for the seven minor heads individually (rule `T(All) < 0.20`), as preregistered.
* The localization criteria were met; there were no failures of the preregistered criteria.

## 6. Interpretation and limits
* **Where the heads retrieve the verdict-related content from:** causally, the transfer into the answer-position head outputs is carried by the value vectors at the **conclusion's final token and the generation-prompt tail**; replacing values at the other ≈ 78 positions (including the query's own) transfers nothing, and random position sets of matching size transfer nothing. This turns the Phase 2.5 *descriptive* source-position finding into a causal one for the answer-position retrieval.
* **But** the two summary groups are individually insufficient (~0.3 each) and jointly exceed the sum of their effects, so the retrieved content is not a single-token read-out; and with all query rows patched, positions outside the summary tokens matter too (F(Remaining) ≈ 0.4) through downstream recomputation. "The heads read the summary positions" is therefore a statement about the answer-position head output, not a complete circuit account.
* The experiment shows sufficiency of the summary-position values for the head-mediated transfer and that the remaining positions contribute nothing in the primary setting; it does not show where the summary-position content is *built*, nor how it is combined with MLP computation. Still exploratory: 217 alignment-validated pairs (half of the matched pairs), a single prompt family, 10 random draws per matching, the localizer and PrOntoQA excluded by design (a matched cross-task experiment would need its own plan), and the verdict direction remains task-general rather than logic-specific.
* Numerical context: recompute validated under the Phase 2.5 criterion (V1–V5); the full-mask equality with the Phase 2.5 results is exact.

## 7. Recommendations (not started)
1. Test where the summary-position values come from: patch the **residual stream** at G1 and the tail positions at layers below the S8 layers (and/or the earlier-layer head/MLP outputs writing there) to see where the transferable verdict content is constructed.
2. A separately preregistered head → layer-22 MLP-neuron mediation study (the downstream amplification here and in Phase 2 — direct writes explain well under half of the coordinate transfer — points to the same-layer MLP as the likely mediator).
3. A matched cross-task (localizer/PrOntoQA) version with paired minimal contrasts, if the shared-verdict claim is to be tested in the same position-restricted way.
