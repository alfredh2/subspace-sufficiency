# Phase 6 plan: where does the verdict-related value content of the conclusion-body positions come from? (PREREGISTERED; approved with 12 amendments, section 11, which take precedence over earlier wording)

**Standing.** Phases 0–5 (datasets, checkpoints, directions, frozen head sets including H\* = {L19H10, L19H17, L19H31}, the frozen Phase 5 selection and scalar direction, all reports and preregistered verdicts, including the Phase 3–5 MIXED verdicts) stay unchanged. This phase traces the *origin* of the value content that H\* read at the conclusion-line key positions, plus a smaller secondary analysis of the Phase 5 pinning result. No new head search, no neuron search, no MVS optimization, no full-model layer scan. Commits without co-author trailers; no push. Nothing here assumes that any layer computes logical validity.

## 0. Facts used (inspected)
* Phase 5 (`docs/phase5_report.md`): H\* copy **value** content (attention weights irrelevant, F_A ≈ 0.01) into the summary rows G1∪G2. At the layer-19 input the content sits at the conclusion body (Concl, F ≈ 0.48–0.51), the conclusion-final token (G1, 0.14) and the fact line (0.05); the three groups together give 0.97. The same effect is obtained with opposite-label, different-content sources (cross-content control), and same-label different-content sources flip 3.7%. A residual patch of `hidden_states[19]` at Concl with full propagation gives T = 0.50 / 0.55 (`num_orig` / `num_rev`); the value-restricted version (only H\*'s values at Concl read at the summary rows) gives 0.17 / 0.20.
* Secondary facts: pinning attention + MLP of layers 20–22 at the summary rows raises the H\* patch effect to 1.57 / 1.48 × the free effect (attention-only 1.40 / 1.35, MLP-only 1.24 / 1.24; layers 20–35 identical); the G1 rows alone give 0.97 / 1.04, the G2 (tail) rows 1.77 / 1.71; the local d_c transfer at index 20 is 0.81 but the final-coordinate transfer only 0.38 (ρ ≈ 2.1); the dose response is convex.
* Data structure (`data/logic.py`): four forms, MP (fact A, conclusion Q, valid), DA (fact ¬A, conclusion ¬Q, invalid), AC (fact Q, conclusion A, invalid), MT (fact ¬Q, conclusion ¬A, valid), each with and without negated consequent. Matched valid/invalid pairs are MP↔AC and MT↔DA (same three sentences, fact and conclusion roles swapped). Validity is a function of form, so form and verdict are confounded *within* matched pairs; they can only be dissociated through same-label sources of a different form. A tokenisation-only census on the test contents (aligned with the Phase 2.5 rule, 224 candidate pairs per type) gives **same-label, different-form pairs MP/MT 99 and AC/DA 99** (feasible, ≈ 200 pairs = ≈ 400 trials), while opposite-label different-form pairs (MP/DA, MT/AC) give only 16 each (not usable).
* Infrastructure reused (validated): `upstream/{patching,data,runner,pipeline,stats}.py` (position-set residual patch, `component_patch`, position sets Rule/Fact/Concl/G1/G2/Other/NonSummary, aligned trial builders for sets A, B, validation; pair- and content-clustered bootstrap, onset logic), `phase5/{patching,runner,pipeline}.py` (row-set head patch, row-restricted delta-form value patch with key groups, summary-row pinning, local `c20`/`w20` readouts, frozen `selection.json`, `w_direction.pt`), `heads/attention.py` (`recompute`, `AttnStash`), `models/hooks.py`, and the lexical/cross-content builders. Measured throughput 7.5–10 ms per full forward.
* Datasets: set A = the 8 test contents (217 aligned pairs, 434 trials per format; previously examined in Phases 2.5–5, disclosed); set B = nonword lexicon seed 0 (43 contents, 400 trials per format; documented prior exposure in the earlier MVS research); validation = 4 contents (selection and gates only). **New: set C = a freshly generated nonword lexicon (`build_contents("nonword", seed=<new>)`, never used in any experiment)**, the only truly unseen data; its yield is measured before use and reported (if fewer than 150 aligned trials per format, C is labelled underpowered).

## 1. Language and levels of evidence
* **Descriptive attribution:** head/component writes projected on d_c, value-share decompositions.
* **Causal influence (sufficiency):** the change of the layer-19 head outputs and of the answer margin after a patch with explicit causal ordering. A patch that does *not* transfer at an early index shows that the content is not sufficiently present *in the transplanted positions under the target's remaining context*; it does not show absence of the information.
* **Information construction** is not claimed from any single measurement. Statements used: 'the conclusion-body residual at index i is (not) sufficient for the H\* value content', 'the component at layer l writes transferable content', 'the fact line still influences the conclusion-line values up to index i'.
* The Phase 4/5 'onset' is a patching-sufficiency property, not the time at which reasoning is performed.

## 2. The central measurement: value-origin curves (restricted path)
For a matched trial (target t, source s, both directions, σ = +1 if the source is valid) and a **patched position group P** ⊂ {Rule, Fact, Concl, G1, combinations} and residual index i ∈ {0,…,19}:
* **Pass A (early exit):** run the target with `hidden_states[i][P] ← source`; everything else natural; stop after the input of layer 19's attention (hook raises a controlled exception; equality with the full-forward stash is tested). Recompute the per-head values `v^A` of H\* from this stash.
* **Pass B:** run the clean target with a **value-only, row-restricted patch**: H\* at the summary rows R = G1∪G2 read values `v^A` at the key groups **KV = Fact ∪ Concl ∪ G1** (attention weights and all other values stay the target's). This isolates exactly one path: *residual at (i, P) → layer-19 values at KV → H\* → summary rows → everything downstream*.
* Outcomes: final margin transfer `T*_V(i,P)`, the verdict-coordinate transfer, and the **head-output transfer** `T*_h(i,P)` = σ-weighted change of the H\* d_c-readout `Σ_h gain_h·z_h` at R relative to its source–target difference; also the local index-20 readouts (`c20`, `w20`).
* Normalisation: `F(i,P) = T*_V(i,P) / T*_V(19,P)`, where `T*_V(19,P)` is the same measurement at index 19 (= the Phase 5 value patch of P: Concl 0.17 / 0.20, Fact+Concl+G1 0.34 / 0.38; regression target). `F(19,P) = 1` by construction. The unrestricted counterpart `U(i,P)` (plain residual patch at i with full propagation, margin and H\* head readout) is reported alongside to show how much of the transfer survives when all paths are open.
* **Component-level version:** patch the attention output or MLP output of layer l ∈ {0,…,18} at P (source components), pass A / pass B as above, giving `F_attn(l,P)`, `F_mlp(l,P)`; these identify which layer's attention or MLP *writes* transferable content at P. Accounting check: for each l the residual patch at l+1 is compared with the sum of the two component effects (interactions reported, not assumed away).
* **Flow from other positions (source of the source):** the same curve with P = Fact, P = Rule and P = Concl+G1, Fact+Concl+G1. Because the injection set KV is fixed, `F(i, Fact)` measures whether patching the fact line at index i still changes the conclusion-line (and G1) values read by H\*, i.e. whether information has already moved from the fact line to the conclusion line by layer i.

### Onsets and windows (pre-specified, as in Phases 4/5)
* **Acquisition onsets** for P = Concl: `i_first(θ)` = smallest i with point `F(i) ≥ θ`; `i_sus(θ)` = smallest i such that the lower 95% bound of `F(i') ≥ θ` for all i' ∈ [i, 19]; θ ∈ {0.5, 0.9}. Sustained is primary; computed for pair-level and content-clustered bounds (both must pass), 'no sustained onset' is reported as such.
* **Closing index of an upstream group** (Fact, Rule): superseded by the remaining-influence definition of section 11 (amendment 3): `F(19,P) = 1` by construction, so a criterion on `F` through index 19 is impossible; the closing index is defined on `R(i,P) = T*_V(i,P)/T_ref` with the fixed reference `T_ref = T*_V(19, Fact∪Concl∪G1)`.
* Windows: early (i_sus(0.5) ≤ 6), middle (7–14), late (15–18), last step (19, i.e. no sustained onset before the layer-19 input).

## 3. Controls distinguishing lexical identity, logical form and verdict
All controls run the same pass A / pass B pipeline and the same position groups.
| source type | label vs target | content | form | what differs | trials (set A, `num_orig`) |
|---|---|---|---|---|---|
| **M** matched sibling | opposite | same | role-swapped (MP↔AC, MT↔DA) | wording of fact/conclusion + form + verdict | 434 |
| **X** cross-content | opposite | different | same family/type | words + form + verdict | ≈ 380 |
| **L** lexical | same | different | same | words only | ≈ 700 |
| **Fm** same-label different form | same | same | different (MP↔MT, AC↔DA) | polarity words + form, **no verdict change** | ≈ 400 |
Readouts for same-label sources have no systematic sign, so controls are evaluated by the **RMS of the H\* d_c-readout change at R**, `ρ_ctrl(i) = RMS_ctrl(i) / RMS_M(i)`, and by flip rates, in addition to the signed transfer `T_h` for M and X. Predictions: the verdict-specific part of the content appears in M and X (signed transfer equal within noise ⇒ not tied to the sibling's words) and **not** in L or Fm (small `ρ_ctrl` ⇒ not lexical, not form-without-verdict). At early indices where the transplanted conclusion words differ, all four source types produce large non-systematic readout changes (ρ_ctrl ≈ 1); the index at which `ρ_ctrl` falls and signed M/X transfer rises marks when verdict-relevant content, rather than word identity, dominates the readout. Because validity is a function of form, **form and verdict cannot be separated further than M versus Fm**; the report says so. Further controls: clean random key groups (count-matched to Concl, drawn from non-summary variable positions **excluding Fact, Concl and G1**, so unlike Phase 5 the random-key pool is a true null), random H\* replacements (5 magnitude-matched head sets, `mms`), the group `Other` (positions before the first token difference; activation equality is **verified by measurement, not assumed**), a norm-matched random direction residual patch at Concl, and a shuffled-source control (source drawn from another pair of the same label class).

## 4. Hypotheses for the primary question
* **O1 Early/lexical origin:** the H\*-relevant content is already present in early Concl residuals: `F(i ≤ 4, Concl) ≥ 0.5`. If L/Fm controls show comparable readout changes (ρ_ctrl ≥ 0.5 at those indices), the early content is lexical rather than verdict-related.
* **O2 Late relational build-up:** the Concl residual acquires the content in a middle/late window after interaction with the fact (and rule) line: `i_sus(0.5)` in the middle or late window, `F(i ≤ 4) ≤ 0.15`, the fact line still influences the values up to the onset (`i_close(Fact) ≥ i_sus(0.5) − 2`), and the verdict-specificity pattern above.
* **O3 Gradual build-up:** `F` rises slowly (`i_sus(0.9) − i_sus(0.1) ≥ 8` layers) without a sharp window.
* **O4 Last-step creation:** no sustained onset before index 19 (`F(18, Concl) < 0.5`): the content appears only at the layer-18 write; component-level analysis then concentrates on layers 17–18.
* **Component hypotheses (given an onset window W):** the writers are attention outputs (`F_attn` jump ≥ 0.3 of the total within W), MLP outputs (`F_mlp` jump ≥ 0.3), or distributed (neither). Non-exclusive.
O-hypotheses are scored separately (supported / partially supported / not supported / inconclusive); mixtures are reported as mixtures.

## 5. Secondary analysis: why does pinning layers 20–22 raise the H\* patch effect ≈ 1.5×?
Restricted to the frozen H\*, rows G1∪G2, set A (both formats), plus one replication check on B.
* **Q1 Localization (layer × component):** pin sets {attn, MLP} × {20, 21, 22} (6 single components); cumulative pins (20; 20–21; 20–22); leave-one-out (pin all five others) and add-one; shares `q_c = (T_pin(c) − T_free)/(T_pin(all) − T_free)` and `q'_c`; if |q_c − q'_c| > 0.20 for the leading component the effect is flagged order-dependent and a Shapley estimate over ≥ 24 random orderings (6 pins each) is added.
* **Q2 Rows:** pin each tail row individually (8 rows) and G1 alone; which rows reproduce the effect (G1 ≈ 1.0, G2 ≈ 1.7 already known).
* **Q3 Verdict-alignment of the counteraction:** descriptive accounting of d_c writes by component at the summary rows (free vs pinned runs): for component (l, c), `ΔW_{l,c} = mean_R d_c·(out_patched − out_target)`; identity `ΔdC(23) − ΔdC(20) = Σ_{l,c} ΔW_{l,c}` (tested); and causal decomposition of the layer-19 write into its d_c-component and orthogonal component (residual patch at index 20 with delta override), with free versus pinned effects.
* **Q4 Dose dependence:** pinned dose curve α ∈ {0.25, 0.5, 0.75, 1, 1.25, 1.5}; ratio T_pin(α)/T_free(α).
* **Q5 Concentration (gated):** only if one component carries ≥ 50% of the effect (Q1), go one level down: its 32 heads (z pin at the summary rows, single heads, plus top-k) or its layer-22 MLP units (U22 versus complement, matched random sets).
Hypotheses: **K1** the counteraction is concentrated in few (layer, component) pairs; **K2** it acts on the tail rows' own recomputation; **K3** it is specific to the verdict-aligned component of the write (the orthogonal component is not counteracted); **K4** it is linear in the patch size (constant ratio over α); **K5** it is generic restoration (would appear equally for the orthogonal component or for random-direction patches). Criteria are in §7.

## 7. Preregistered criteria (all on answer-margin transfer unless stated; point and the stated bound must pass on **both** pair-level and content-clustered intervals; for set A additionally in every leave-one-content-out recomputation; both formats; failures reported literally)
* **V0 validity:** Stage-0 tests and pilot gate pass; denominators above floors (margin gap ≥ 10 logits, coordinate gap ≥ 2.0); otherwise 'not evaluable'.
* **Onset classification:** from `i_sus(0.5)` of `F(i,Concl)` (margin) as in §2; the head-output transfer `T*_h` must give an onset within ±2 indices (otherwise 'outcomes disagree', reported).
* **O1 supported:** `F(4,Concl)` point ≥ 0.5 and lower bound ≥ 0.4, and `ρ_ctrl(4)` for L and Fm both point ≤ 0.25 and upper bound ≤ 0.35 (early content is verdict-related). **O1-lexical:** `F(4)` point ≥ 0.5 with `ρ_ctrl(4)` point ≥ 0.5 for L or Fm (early content not verdict-specific).
* **O2 supported:** `i_sus(0.5)` in the middle or late window; `F(4)` point ≤ 0.15 and upper bound ≤ 0.25; `i_close(Fact) ≥ i_sus(0.5) − 2` (point; `i_close` as defined in section 11); M and X signed head-output transfers at index 19 within 0.10 of each other; `ρ_ctrl(19)` for L and Fm point ≤ 0.25 and upper bound ≤ 0.35; random key groups, random head sets and `Other` ≤ 0.15 × `T*_V(19,Concl)` (mean) and ≤ 0.30 × (max).
* **O3 supported:** `i_sus(0.9) − i_sus(0.1) ≥ 8` and not O1/O2. **O4 supported:** no sustained onset before 19 and `F(18)` upper bound < 0.5.
* **Component hypotheses:** a layer l is a writer if the component's `F_comp(l)` point ≥ 0.3 × the total `F(l+1) − F(l)` summed over the window and lower bound > 0.05; the attention / MLP split is reported with the order-dependence caveat.
* **Secondary (§5):** K1 supported if the top component has `q_c ≥ 0.30` and `q'_c ≥ 0.30` and the top two reach ≥ 0.60 of the effect; K2 supported if tail-row pins reproduce ≥ 0.80 of the all-row increase and G1 alone ≤ 0.20 of it; K3 supported if the d_c-component-only patch shows `S_pin ≥ 1.3` (lower bound ≥ 1.15) while the orthogonal-component patch (if its free effect is above the floor) shows `S_pin ≤ 1.15`; K4 supported if T_pin/T_free at α = 0.5, 1, 1.5 lie within ±0.15 of each other; K5 supported if the orthogonal or random-direction patch shows the same attenuation of its local readout between index 20 and 23 as the d_c-aligned patch (ratio of persistence within ±0.15). The accounting identity must hold within 5% of `|ΔdC(20)|`.
* **Independent evaluation:** a hypothesis counts as replicated if its onset window and its sign/size criteria (point estimates) hold on set B and set C; C is decisive when A and B disagree. Outcomes: **SUPPORTED** (O-hypothesis plus controls, replicated on B and C), **MIXED** (any named partial: one format only, only on A, onset windows disagree between sets by > 3 indices, controls partly failing), **NOT SUPPORTED/INCONCLUSIVE** (V0 fails, intervals wider than the thresholds' margins, or no pre-specified O-hypothesis holds; the observed curve is then reported descriptively as such).

## 8. Numerical correctness tests (required before experiments)
1. **Two-pass regression:** at i = 19 with P = Concl (and Fact+Concl+G1) the pipeline reproduces the Phase 5 V-patch transfers (0.17 / 0.20 and 0.34 / 0.38 on set A) within ±0.005 and the unrestricted patch the Phase 5 `res19|Concl` (0.50 / 0.55).
2. **Early exit:** the stash captured at the layer-19 attention input after the early-exit forward equals the stash of a full forward bit-for-bit; hooks are removed after the controlled exception (also on error).
3. **Patch mechanics:** residual patch at index i changes nothing at layers < i; positions earlier than P (and positions not attending to P) are unchanged at all later layers; for every group the equality of source and target activations at the patched index is measured and reported (a group is classified as an exact no-op only where the measured difference is exactly 0); patch with source = target is the identity.
4. **Component patches:** attn + MLP source components at layer l together with a source residual at index l reproduce the source's `hidden_states[l+1]` at P exactly (tiny model fp32 exact; Qwen within the measured noise floor); each component patch changes only its own write.
5. **Value-injection path:** the injected values `v^A` equal the patched run's values at KV (direct comparison); restricting to KV and rows R leaves all other rows/keys unchanged; the injected set with `v^A = v^t` (no patch) is the identity.
6. **Control builders:** all four source types satisfy equal token length and identical line spans and category masks between target and source; same-label controls have gap |Y_s − Y_t| below the floor and are therefore never used for ratio transfers; Fm pairs have the same label and different forms (verified from the form metadata); set C contents are disjoint from every earlier set (word-level check).
7. **Pinning accounting:** `ΔdC(23) − ΔdC(20) = Σ ΔW_{l,c}` at the summary rows (exact in fp32 tiny; Qwen within tolerance); single-component pins replace only that component; pin without patch is the identity; shared Phase 5 pin verification (max difference 0.0).
8. **Statistics:** ratio algebra, onset/closing-index detection on synthetic curves (monotone, plateau, non-sustained, never-reached), RMS-ratio estimator and its bootstrap, Shapley ordering sampler determinism (`crc32` seeds), pair/content clustering of control trials (target pair and content as clusters), existing test suite passes.

## 11. Approval amendments (binding; they supersede earlier wording)
1. **Main experiment kept.** The two-pass causal-path experiment (restricted pipeline of section 2) remains the primary measurement of when earlier residual representations become sufficient to supply transferable value content through H\*.
2. **Signed, unnormalised curves reported.** For every curve the unnormalised signed transfer `T*_V(i,P)`, the raw final answer-margin change (logits, signed toward the source), the raw head-output change (σ-weighted d_c-readout change of H\* at the summary rows, readout units) and a direct pre-downstream value measure `vproj` (projection of the injected H\* value change on the source–target value change at KV) are reported next to `F(i,P)`, each with pair-level and content-clustered intervals, and the denominators `T*_V(19,P)` with their intervals. **Monotonicity is not assumed.** `F(i,P)` is reported only where its denominator is defined, i.e. both lower bounds of `|T*_V(19,P)|` are ≥ 0.08 (transfer units); otherwise `F` is *undefined* for that P (expected for Rule, Fact and G1 alone) and only the unnormalised curves and `R` are used. A sustained onset is interpreted as **causal availability under the intervention**, not as the moment of computation.
3. **Remaining-influence measure and closing index.** For upstream groups P ∈ {Fact, Rule} (and, descriptively, G1 and Concl): `R(i,P) = T*_V(i,P) / T_ref`, `T_ref = T*_V(19, Fact∪Concl∪G1)` (the fixed, clearly non-zero reference: 0.34 / 0.38 on set A). `R` is **undefined** (no closing index is forced) unless both lower bounds of `T_ref` are ≥ 0.10. `i_close(P)` = the smallest grid index i such that for **every** grid index i' ∈ [i, 19] the upper 95% bounds (pair-level and content-clustered) of `R(i',P)` are ≤ 0.10; if no index satisfies this (including i = 19), 'no closing index' is reported; if even i = 0 satisfies it, 'no influence at any index' is reported. For i ≥ `i_close(P)`, patching P no longer changes what H\* read at KV beyond 10% of the reference effect.
4. **Component-level interventions: direct write versus total influence.** For component c ∈ {attn, MLP} at layer l ≤ 18 and patched group P, three distinct quantities are measured and never assumed equal: (a) **direct write**: only the source–target difference of that component's output at P, `ΔW_{l,c} = out^src_{l,c}[P] − out^tgt_{l,c}[P]`, is added to `hidden_states[19]` at P (all other component outputs, including the same layer's other component and every later layer, are held at the target's clean values; implemented as a residual patch at index 19 with delta override); (b) **total influence**: only that component's output at layer l is replaced at P and all downstream computation (layers l..18) recomputes naturally; (c) **joint** attn+MLP of layer l patched together (total and direct versions). Reported: the three effects, the interaction `I_l = T(joint) − T(attn) − T(MLP)` for both versions, and the difference total − direct (the downstream-recomputation contribution). No claim that independent attention and MLP patches reproduce the combined effect.
5. **No assumed no-ops; token identity is not activation identity.** The group `Other` (positions before the first token difference) is equal by causality, but this is **verified, not assumed**: for every group, trial and index the maximum absolute difference and the fraction of positions with exactly equal activations between source and target are measured and reported before a patch is classified as a no-op. Positions with identical tokens but context-dependent activations are treated as ordinary groups. A new token-identity partition is added: `X_same` / `X_diff` for X ∈ {Concl, Fact, G1, Rule, KV} = positions where source and target tokens are identical / different. Patching `Concl_same` (identical tokens, context-derived activations) separates context-derived content from wording.
6. **All onset thresholds defined; unstable trajectories classified.** `i_sus(θ)` for θ ∈ {0.1, 0.5, 0.9}: the smallest grid index such that the lower 95% bounds (pair-level and content-clustered) of `F(i')` are ≥ θ for all grid indices i' ∈ [i, 19]; `i_first(θ)`: smallest grid index with point `F ≥ θ`. Trajectory classes (on the grid, for each P with defined F): **sign-reversing** (upper bounds of `F(i) < −0.05` for some i < 19), **non-monotone** (some i < j with `F(i) − F(j)` point ≥ 0.15 and lower bounds of the difference ≥ 0.05), **monotone rise** (otherwise, with `F(19) − F(0)` ≥ 0.5), **flat/undefined** otherwise. A non-monotone or sign-reversing curve has its sustained onsets reported as defined above but is classified `unstable` and cannot support O1–O3 without a statement of the instability. The hypothesis O3 uses `i_sus(0.9) − i_sus(0.1) ≥ 8`.
7. **Framing of the same-label / different-form control.** Fm keeps its role, but validity is determined by form in this benchmark; a positive result is reported only as 'verdict-correlated information that generalises across the tested forms (MP↔MT, AC↔DA) and lexical content', not as abstract logical validity and not as separating validity from argument structure.
8. **Set C frozen before any intervention.** Seed (`20261023`), the generation procedure (`build_contents('nonword', n=48, seed=20261023)` at the repository revision), the resulting contents, the family list, the alignment eligibility rules (Phase 2.5 `pair_alignment`, equal token length, identical category masks, minimum 150 aligned trials per format else 'underpowered'), the deterministic family-stratified sampling (up to 400 trials, seed 1) and the manifest of eligible pairs are written to `results/phase6/set_c.json` and committed **before any intervention on C**; only tokenisation (no model forward) is used to build the manifest, and word-level disjointness from every earlier lexicon is checked. C is an unseen lexical replication set, not evidence of generalisation to fundamentally new logical computations. Nothing is tuned on B or C; B and C run only under hash-frozen code and configuration.
9. **Secondary pinning analysis retained**, including individual layers 20–22 (attention and MLP separately), summary-row localisation (tail tokens individually), the verdict-aligned versus orthogonal components of the layer-19 write, and the dose×pin curve; interaction (2×2 attention×MLP per layer, cumulative sets) and order dependence (add-one versus leave-one-out, Shapley orderings) are reported and component effects are never treated as additive.
