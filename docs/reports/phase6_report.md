# Phase 6 report: where does the value content that H\* = {L19H10, L19H17, L19H31} read at the conclusion line come from?

Plan: `docs/plans/phase6_plan.md` (committed with the 12 approval amendments before implementation). Tables: `results/phase6/report_tables.md`; mechanical scoring: `results/phase6/criteria_verdict.json`; raw per-trial arrays: `results/phase6/*.npz`; frozen unseen set C: `results/phase6/set_c.json`. Earlier results, checkpoints, the frozen H\* and all earlier verdicts are unchanged. GPU: **2.72 h** of logged job time (soft budget 3–4 h; model loading adds a few tenths of an hour).

## Outcome: **MIXED**, reported as scored under the frozen criteria
* **O1 (early, verdict-related origin): not supported.** The restricted-path sufficiency of the conclusion-body residual is already large at the embedding level, `F(4, Concl)` = 0.63 / 0.77 (set A `num_orig` / `num_rev`), 0.74 / 0.85 (B), 0.82 / 0.92 (C), but the same-label controls change the H\* readout about as much, so the early content is flagged **lexical (O1-lexical)** where the controls exist.
* **O2 (late relational build-up): not supported** (sustained half-onset at index 0; `F(4)` far above 0.15; `ρ_ctrl(19)` for L is 0.28–0.35 and for Fm 0.57–0.61, above the 0.25 limit).
* **O3 (gradual build-up): the literal criterion is met** on A, B and C (`i_sus(0.9) − i_sus(0.1)` ≥ 8 in all `num_orig` sets, `num_rev` A and B; set C `num_rev` is classified non-monotone and therefore unstable). **I do not read this as a build-up from zero:** `F` starts at 0.58–0.85, rises slowly, dips at indices 15–16 and reaches 0.9 only at index 19 (the trajectory class is *flat* for five of six sets). **O4 (last-step creation): not supported.**
* **Secondary (pinning) result:** the 1.5× increase is produced mainly by **layer-20 attention at three summary rows**, specifically by **heads L20H9 and L20H19**, and it acts on the part of the layer-19 write that is **orthogonal to d_c**.

## Validation (all gates passed before any dependent experiment)
* 7 new test groups (`tests/test_phase6.py`; full suite 127 tests): early-exit stash equals the full-forward stash bit-for-bit and hooks are removed on error; the two-pass path at the layer input equals the validated direct value patch; source = target is the identity; **activation equality is measured, not assumed** (`Other` equal by causality, identical-token positions after the first difference are *not* equal); the direct-write identity (`hidden_states[19] = target + ΔW`) holds exactly and differs from the total (recompute) version; pin/accounting identities; onset, closing-index, trajectory-class and RMS-ratio statistics on synthetic curves; token-identity partition and Fm control builders.
* Pilot on set A: the two-pass pipeline at index 19 reproduces the Phase 5 value patches and the residual patch **bit-exactly** (0.1686 for Concl, 0.3372 for Fact+Concl+G1, 0.5002 for the unrestricted Concl patch; zero difference of every margin); the accounting identity Δd_c(23) − Δd_c(20) = Σ component writes holds (max residual 0.006, 0.7% of the local shift); pin verification max difference 0.0; the `Other` group is exactly equal at indices 0, 10, 19. Measured equality for identical-token positions (`Concl_same`): equal at index 0, never equal at indices 10 and 19 (max difference 5–12), which is why the amendment against assuming no-ops mattered.
* Control builders (set A): Fm 396 trials (198 pairs; MP↔MT, AC↔DA), L 708, X 382; set C 400 trials per format (not underpowered).

**What the early sufficiency means.** Patching only the conclusion-body *token embeddings* (index 0) puts the source's conclusion words into the target's context. In the matched pair the target's fact line then contains the sibling's conclusion proposition, so layers 1–18 compute the value content of a *hybrid* prompt; the curve measures sufficiency of the conclusion residual under the target's remaining context, not information transport from an already-formed verdict. The token-identity partition shows where it sits: **`Concl_diff` (positions whose tokens differ) carries 0.097 of the 0.118 it has at index 19 (`F` = 0.82) already at index 0, while `Concl_same` (identical tokens, context-derived activations) carries ~0.00 until index 16 and 0.035 only at index 19** (R = 0.10 of the reference). On nonword sets B and C `Concl_same` contributes 0.012–0.014 at index 19. Context-derived content at identical-token positions therefore appears only in the last three layers.

## Flow from other positions and writers
* **Fact line (remaining-influence `R(i, Fact)` = `T*_V(i,Fact)`/`T_ref`):** 0.38 at index 0 (A; 0.42 for `num_rev`, 0.38–0.42 for B/C), flat until index 8 (0.40), then 0.33 (10), 0.26 (12), 0.18 (14), 0.17 (16), 0.12 (17), 0.10 (18), 0.06 (19). The closing index is **19** in all sets (influence persists through index 18); `F` is undefined for Fact, G1, Rule and `Concl_same` (denominator lower bounds 0.005–0.042 below 0.08). Rule: `R` ≈ 0 at every index ('no influence at any index'; note the Rule positions themselves are not equal between source and target after the first difference, max difference up to 11, so this is a measured null, not an assumed one). The fact-to-key flow therefore happens mostly in layers 9–17.
* **Writers into the conclusion body (component patches, joint attention+MLP, set A `num_orig`).** Total influence (downstream recompute) of the layer-0 outputs is 0.097 (= the whole index-0 effect) while their **direct** write is 0.001: the early content is *recomputed* through layers 1–18, not written directly. Layers 15–18 carry the next increments (total joint 0.059, 0.046, 0.029, 0.089), and the only substantial **direct** writers are **MLP outputs of layers 17–18** (direct 0.019 and 0.066; `num_rev` layers 17–18 also). By the frozen writer criterion (window 0–19, threshold 0.3 × rise) the writers are layers 0, 15, 16, 17, 18 (total) and layer 18 MLP (direct); attention and MLP are non-additive (layer 0 interaction −0.073, layer 18 −0.015). The total-minus-direct difference (+0.096 at layer 0, +0.05 at layer 15) quantifies the downstream-recompute contribution.
* Closing/trajectory: `Concl_diff` is non-monotone (peak at 14, dip at 16–18); `Concl+G1` is a monotone rise (0.29 → 0.76 of the reference).

## Secondary: why does pinning layers 20–22 raise the H\* patch effect ≈ 1.5×?
* **Where (layer × component), set A / B, both formats:** all six components pinned: `S_pin` = 1.57 / 1.48 (A), 1.67 / 1.64 (B). **Pinning layer 20 alone reproduces essentially all of it** (cumulative T: layer 20 0.542, layers 20–21 0.527, 20–22 0.544 against T_free 0.348). **Layer-20 attention** is dominant: add-one share q = 0.74–0.81 (A), leave-one-out q' = 0.50–0.60; Shapley share (24 orderings) 0.65 [0.59, 0.73] / 0.66 [0.58, 0.75]; layer-21 MLP 0.21–0.27, layer-20 MLP 0.11–0.17, layer-22 attention 0.08, **layer-21 attention is negative (−0.11 to −0.15)**. Order dependence: |q − q'| > 0.20 for the leading component in A `num_rev` (0.24), hence the Shapley estimate; the 2×2 attention×MLP interaction is small (−0.02 at layer 20, ~0 at layers 21–22). Component effects are not additive (add-one shares sum to 1.5).
* **Heads (gated Q5, ranking frozen on the validation contents):** pinning the output of **L20H9 alone accounts for 0.82–0.93 of the layer-20 attention-pin increase and L20H19 for 0.41–0.48**; the shares exceed 1 jointly (non-additive; the remaining heads partly oppose). The all-32 z-pin reproduces the attention-component pin exactly (identity check diff 0.0000).
* **Which rows:** pins at the G2 rows alone give 0.60–0.64 of the all-row increase and at G1 0.37–0.48 (K2 not met); individually **three rows account for essentially all of it**: the conclusion-final token (G1), the second tail token (the newline after `<|im_end|>`, 0.31–0.51) and the third (`<|im_start|>`, 0.16–0.28); the other tail tokens give ≤ 0.02.
* **Verdict alignment:** the layer-19 write is nearly a full d_c-coordinate write locally (0.80 of the gap), yet its **d_c-aligned component alone has `T_free` = 0.024** (below the 0.05 floor, `S_pin` undefined), while the component **orthogonal to d_c carries 0.24–0.30 of the 0.31–0.39 total and has `S_pin` = 1.64** (A `num_orig`; 1.6–1.7 across sets). K3 is not supported and K5 is not evaluable (it needs a defined d_c-component effect); the counteraction acts on the orthogonal part of the write, and **the d_c-aligned local shift is by itself nearly inert for the answer margin**. Descriptive d_c accounting does not identify the causal counteraction: the d_c writes of layers 20–22 (attn/mlp) are +0.05/−0.19, +0.07/+0.02, +0.04/−0.02, i.e. layer-20 MLP opposes the d_c shift most, while pinning layer-20 attention matters most causally.
* **Dose dependence (K4 not supported):** T_pin/T_free = 1.34, 1.52, 1.73, 1.57, 1.34, 1.24 for α = 0.25, 0.5, 0.75, 1.0, 1.25, 1.5 (A `num_orig`; B 1.59 → 1.37): not constant, peaking near α = 0.75 and shrinking at larger doses.
* **Scoring:** K1 (concentration) is partially supported (one dominant component, layer-20 attention, in all four sets; the top-two criterion holds for `num_rev` A and B but not `num_orig`); K2, K3, K4 not supported; K5 not evaluable. Identity checks hold (residual ≤ 0.7% of the local shift).

## Independent evaluation
Set A is previously examined (Phases 2.5–5); B (nonword seed 0) has documented prior exposure in the earlier MVS research; C was frozen before any intervention (seed 20261023; contents, eligibility rules and manifest hash in `results/phase6/set_c.json`; 4 of its 192 words coincide with earlier lexicons, reported in the manifest). The primary patterns (early `F` ≥ 0.58, sustained θ = 0.5 onset at index 0, L-control ρ 0.28 at index 19, X ≈ M signed readout, Fact closing index 19, layer-15–18 writers, layer-20 attention counteraction by L20H9/L20H19) **replicate on B and C** within a few hundredths, apart from set C `num_rev` being classified non-monotone. This is an unseen *lexical* replication, not evidence for fundamentally new logical computations.

## What is and is not shown
* Shown: the sufficiency of conclusion-body residuals for H\*'s value content is largely set by token/surface frame identity in the target context; verdict-correlated, content-independent readout strengthens with depth and is completed in layers 15–18 (MLP outputs of 17–18 write directly); the fact line keeps influencing the keys' values through layer 18; context-derived content at identical-token positions is a late, small component.
* Not shown: that any layer computes logical validity; that the surface-form features are not themselves a shortcut for validity (validity is a function of form here); where the verdict *itself* is first represented; necessity of any component (these are sufficiency/pathway measurements); that the d_c-aligned component is irrelevant outside this patching set-up.
