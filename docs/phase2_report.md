# Phase 2 report — attention-head contributions to the consensus *verdict direction*

**Wording.** The target is the verdict direction `d_c` (hook `residual_index 23`), an accept/reject verdict channel shared by logic, the language localizer and PrOntoQA; nothing here supports "logic heads". Phase 0–1 results, checkpoints and the Phase 1 verdict (**mixed / inconclusive**) are unchanged.
Plan and frozen rules: `docs/phase2_plan.md` (committed before any result). Tables: `results/phase2/report_tables.md`; criteria: `results/phase2/criteria_verdicts.json`. ≈ 3.0 of the 4 GPU-hours were used (≈1.2 h of that went to two bug-induced reruns, below). 85+ tests pass.

## Bottom line (frozen rule): **mixed / inconclusive — very strong geometric and causal evidence for a small set of native heads, but two preregistered criteria fail narrowly and the routing/content analysis was cancelled**
| frozen component | result |
|---|---|
| Recompute gate (routing/content, A/V patching) | **FAILED** (worst-case d_c-contribution error 2.7 % / 2.4 % of std at layers 19 / 22 vs 2 % limit) → source-position, routing/content and A-only/V-only analyses **not run** |
| H-geometric | **passed** (concentration vs layer-matched Haar-block and permuted-block nulls; held-out reconstruction) |
| H-causal (S8) | effect size, control comparisons (Holm), bootstrap, magnitude-ranking contrast, direct/actual sign all **pass**; **C3 side-effects fails** (verdict-free shifts −1.40 MMLU, −2.49 word recall vs 1.0 limit; KL 0.016 passes) → H-causal **not passed** |
| H-patching | S8 transfer 0.90 and non-verdict tasks ≈ 0 pass; **random-head criterion fails** (max |transfer| 0.126 for all-position random draws vs < 0.02 limit) → **not passed** |
Because H-causal and H-patching do not both pass, the mechanical label is *mixed / inconclusive*, not "sparse head implementation supported". The substantive picture (below) is nonetheless a sharp one.

## Recompute gate (amendment 9) — failed; what was and wasn't run
On real padded Qwen3-8B batches (16 prompts, lengths 76–93; layers 0/10/19/22): layer-level relative L2 error 0.0011–0.0017, median per-head error 0.0012–0.0018, attention rows sum to 1 exactly — all well inside the preregistered tolerances. The d_c-contribution criterion, applied as the **worst-case** error over all real positions and heads, was 0.012, 0.018, **0.027**, **0.024** of std (limit 0.02) → gate FAIL. Supplementary context (not used to change the verdict): RMS error 0.05–0.16 % of std, p99 0.4–0.6 %, last-position maximum ≤ 1.0 %; the recompute is closer to the default sdpa path (0.1–0.2 %) than eager is to sdpa (0.6–2.9 %), so the failure is a rare-outlier-position effect. Per the plan I did **not** re-interpret the criterion; routing/content decomposition, source-token attention analysis and A-only/V-only patching were cancelled. Head-output decomposition, ablations and full-`z` patching (which use the model's own `o_proj` inputs) continued. **Source-position findings are therefore absent from this report.** Re-opening them needs an amendment (e.g. an RMS/last-position tolerance, or using the model's native eager attention weights as a descriptive-only supplement).

## Stage 1 — headwise concentration (layers 0–22, 736 heads)
* Net attention class difference (valid − invalid) of `c = d_c·h₂₃`: **+8.54** (held-out +8.37), Σ|Δ_h| = 11.45, κ = 1.34 (positive mass 9.99, negative 1.46). Layer signed contributions: L22 +4.88, L21 +2.28, L20 +0.82, L19 +0.46, others ≈ 0. Identity `Σ_h s_h = d·attn_out` holds (rel. error 0.011); split-half Spearman of |Δ_h| 0.79 → gate S1 passed (absolute attention share 0.44).
* **Frozen S8** (pooled top-8 by training |Δ_h|): L22H5 (+4.60), L21H19 (+1.90), L20H8 (+0.78), L22H8 (−0.55), L22H15 (+0.36), L19H10 (+0.30), L22H6 (−0.21), L22H4 (+0.21). S8 = 1.1 % of heads, 77.8 % of Σ|Δ| (held-out 78.2 %), 86.5 % of the signed net. L22H5 alone: 40 % of |Δ| mass and 54 % of the held-out net signed difference (per-example R² 0.78).
* **Native vs layer-mass-matched nulls** (alternative coordinate decompositions of the same update, *not* heads): top-8 share native 0.778 vs 0.189 (Haar-rotated 128-dim blocks, n = 20, native above all; ratio 4.1; N_eff 5.0 vs 73) and vs 0.335 (permuted-coordinate blocks, n = 1000, above all; ratio 2.3); within layers 19–22 the top-2 head share is 0.77 vs 0.10 (N_eff 2.1 vs 29). Early layers 0–18 (native 0.478 vs 0.20) and layers 19–22 (0.793 vs 0.19) both exceed the null, so the result is not carried by the last layers alone. **Context against over-reading:** against the head-shuffled-alignment null (permuting gain slices among heads of a layer) the native top-8 share is only 1.31× the null mean and **not** above every draw (max 0.864): a good part of the concentration is already in the per-head marginals (a few heads have large class-mean differences and large gains).
* **Held-out reconstruction:** top-8 heads recover 86.8 % of the held-out net attention class difference (R² 0.979; top-32 98.7 %); random-8 sets 0.9 % on average (the ≈1 % of draws containing L22H5 reach ≈54 %); Haar-rotated blocks 19 %.
* **Cross-task:** head |Δ| rankings are shared (Spearman 0.66–0.69; top-8 overlap logic∩localizer 4, logic∩PrOntoQA 6, localizer∩PrOntoQA 6, ≈0.09 expected). Concentration holds for the localizer (top-8 0.578) and PrOntoQA (0.697), for the three per-seed directions (0.77–0.78) and weaker at the conclusion-end position (0.498).

## Stage 3 — causal importance (confirmatory set; `E_gap` = signed fraction of the d_c-ablation margin-gap reduction; raw reductions always shown)
d_c ablation reduces the margin class gap by 23.4 logits (logic `num_orig`), 15.9 (`num_rev`), 26.4 (localizer), 5.0 (PrOntoQA: denominator < 10, so E_gap undefined; raw reductions only).
* **Mean-replacement ablation of S8: E_gap 0.861 (`num_orig`), 1.138 (`num_rev`), 0.489 (localizer); raw gap reduction 20.2 logits; verdict-coordinate class gap at the hook 18.9 → 1.4.** Dose–response: top-1 head (L22H5) 0.385/0.536/0.226; top-2 0.569; top-4 0.678; S16 0.910; top-64 1.132. Last-position-only S8: 0.515/0.769.
* **Not a bias shift:** S8 shifts the mean margin by +2.9 logits (d_c ablation: +15.3), and mean-ablated S8 keeps AUC 0.972 — gap compression without the constant-"valid" collapse. **Resample ablation** (class-agnostic replacement from another prompt) drives the logic AUC to **0.613** (E_gap 1.02): the selected heads carry the verdict signal that downstream computation uses; the mean-replacement AUC is higher because the residual signal still ranks examples once the heads' variance is removed.
* **Controls at k = 8 (30 draws per family):** random 0.070 [−0.16, 0.27], layer-restricted 0.104 [−0.10, 0.29], magnitude-matched 0.131 [−0.01, 0.28], alignment-matched 0.146 [0.03, 0.27] (num_orig); similar for `num_rev`; localizer ≈ 0. Native exceeds every sampled draw in every family and format, with z-scores 4–12 (Shapiro p 0.36–0.88), Holm-adjusted p ≤ 1e-12 over the 8 primary comparisons, and paired-bootstrap CIs of E_native − mean(E_control) such as [+0.77, +0.81] (random). **Resolution caveat:** with n = 30 the smallest empirical p is 1/31 = 0.032 and 8 comparisons need ≈ 0.006, so "exceeds all draws" alone is not significance; the Holm-corrected z-tests rely on approximately normal control distributions. These controls are far from zero (maxima up to 0.29): ablating random sets of late-layer heads removes part of the verdict signal too, unlike random MLP units in Phase 1.
* **Alternative rankings:** signed-Δ ranking (E 0.984), localizer-ranked (0.660) and PrOntoQA-ranked (0.611) top-8 sets are also effective; **output-magnitude-only ranking is the opposite case** (E −0.148: it does not touch the verdict, KL 0.061) — beating it by ≥ 0.10 is satisfied by a wide margin.
* **Direct vs downstream (separately reported):** the heads' own writes change the verdict-coordinate class gap by −5.06 (S8) but the actual change after recomputation is −17.5 (18.9 → 1.4); for L22H5 alone −4.6 direct vs −11.9 actual. Most of the effect is therefore *downstream* of the heads' direct writes (see Stage 4: the layer-22 MLP reads the same layer's head outputs).
* **Single-head map, layers 19–22 (128 heads):** 35 heads have |E_gap| ≥ 0.05; L22H5 (0.385), L20H8 (0.212), L21H19 (0.131) lead; several heads outside S8 in layer 19 reach 0.10–0.13 and some S8 heads act in the opposite direction (L22H6 −0.098), so the training-|Δ| ranking and single-head causal effect agree only moderately (Spearman 0.36).
* **Side effects (C3 fails):** WikiText KL 0.016 (limit 0.02), but verdict-free margin shifts are −1.40 (MMLU), +0.38 (Stroop), **−2.49 (word recall)**; 1-digit multiplication drops from 1.00 to **0.78** (S16: 0.59); 8-token continuations match the intact model on 0.75–1.00 of prompts. For context, 8-head random sets reach verdict-free shifts up to 4.1 (random), 4.6 (layer-restricted) and 2.2 (magnitude-matched); the native perturbation is larger (mean ‖Δh‖ 32.8 vs 23.7–28.0). The d_c ablation itself leaves multiplication at 1.00. So the heads' ablation is *not* purely verdict-selective.

## Counterfactual patching of head outputs (full-`z` only)
Alignment validation accepted 217 of 448 matched pairs (231 rejected: `line spans differ`); only these were used for all-position patches (434 trials per format); last-position patches use all 448 pairs.
* **S8 patched from the valid into the invalid example (and vice versa), aligned pairs, all positions: margin transfer +0.904 (`num_orig`) and +0.907 (`num_rev`), flip-to-source 94 % / 93 % of clean trials; last position only +0.757 / +0.707 (82 % / 77 %); all pairs, last position +0.775 / +0.723.** L22H5 alone: 0.48 / 0.44 (all positions). The coordinate transfer after recomputation is 0.95 while the immediate (direct) transfer is only 0.39: again most of the effect is downstream.
* **Controls:** random heads: last-position max |transfer| ≤ 0.020; all-position max 0.125 (random), 0.126 (layer-restricted), 0.023 (magnitude-matched), with means 0.007–0.021 — **this exceeds the frozen < 0.02 random-head limit and is why H-patching is reported as not passed** (native is ≈ 7× the worst random draw; the large draws presumably contain individually influential late-layer heads). Same-label lexical controls (aligned pairs): verdict change 6 % (S8) vs 0.4 % for random sets, |Δmargin| 2.7.
* **Non-verdict tasks (S8, last position, 150 unmatched pairs each):** MMLU +0.032, Stroop −0.003, word recall +0.029 (all < 0.05 ✓) — but note the coordinate shifts there are large (0.76–0.80 transfer of the verdict coordinate) without any margin effect: those tasks do not read the verdict coordinate.
* **Verdict tasks:** localizer transfer 0.423 (flip 50 %), PrOntoQA 0.611 (54 %), logic (unmatched) 0.760. As in earlier phases, the mechanism patched is a shared verdict signal, not logic-specific content; a prediction flip is not evidence of abstract logical content.

* **Interactions** (normalised signed effects; classification uses an equivalence rule — a CI containing 0 is not treated as additivity): S8 + MLP-512 on `num_orig`: I = **−0.108 [−0.145, −0.072]** → sub-additive (redundant); on `num_rev` −0.279 (redundant); on the localizer **+0.224 [+0.206, +0.242]** → super-additive. L22H5 + MLP-64/512 on `num_orig`: I = −0.07/−0.035, equivalent to additivity (90 % CI within ±0.10), but `num_rev` redundant (−0.18/−0.15) and localizer −0.15 (redundant) for MLP-64. So attention and MLP effects are **partly redundant on logic and partly synergistic on the localizer; they are not additive in general.**
* **Does the combination explain substantially more?** The combined native-component ablation removes 111 % of the d_c-ablation margin-gap reduction (and brings the verdict-coordinate class gap to 0.5), versus 86 % for the heads alone and 36 % for the MLP set alone: the combination closes the gap to direct verdict-direction ablation (≥ 0.80), but the increment over the heads alone is modest (+0.25, partly redundant) and attention-only already comes close. Specificity is clear: generic random-head + random-unit combinations give 0.10. The sole-component picture is reversed from Phase 1: heads explain more of the answer-level effect than the MLP units, yet the head effect is largely mediated downstream (e.g. through layer-22 MLP neurons) rather than through the heads' own direct writes.
* E > 1 means the native-component ablation compresses the margin gap *more* than ablating the 1-D direction; and, unlike d_c ablation, it does so without the large "valid" bias shift (shifts ≈ +2 to +3 vs +15), indicating the native components carry verdict-relevant information beyond the single coordinate and not a pure d_c bias. Side effects grow with combination (KL 0.018–0.030; verdict-free shifts −1.5 to −3.3).

## Summary answers
* **Headwise concentration:** extremely concentrated in a handful of native heads (S8: 78 % of |Δ| mass, 87 % of the signed net, all confirmed held-out), far above layer-matched rotated or permuted decompositions; partly attributable to head marginals (shuffled-alignment context).
* **Causal importance:** ablating S8 reproduces 86–114 % of the d_c-ablation gap reduction (resample ablation drives AUC to 0.61), clearly beyond random, layer-restricted, magnitude- and alignment-matched controls and beyond an output-magnitude ranking; side effects on verdict-free tasks and arithmetic are non-trivial (C3 fails).
* **Source-position findings:** none (recompute gate failed; routing/content, attention-pattern and A/V analyses cancelled).
* **Cross-task:** the same heads carry the signal for logic, localizer and PrOntoQA (shared rankings; causal and patching effects on all three; none on verdict-free tasks).
* **Attention/MLP interactions:** partly redundant on logic, synergistic on the localizer, not additive; combination closes the gap but adds only modestly over the heads alone.

## Deviations, bugs and limitations (all affected results were rerun or flagged)
* **Recompute gate failed** (above); routing/content and A/V patching not run.
* **Non-deterministic control seeds** (Python `hash()` of a string) in the first Stage-3 run: the k = 8 controls were discarded and rerun with deterministic seeds and recorded sets (`results/phase2/stage3/control_sets.json`). The k ∈ {2, 4, 16, 32} control draws were kept from the first run for effect-size context only (their head sets were not recorded); k = 64 and the patching controls use the deterministic, recorded versions (k = 64 magnitude-/alignment-matched families omitted: impossible within layer 22).
* **Silent skipping of all-position patches** in the first patching run (batches containing any unaligned pair); fixed with a hard error, and all-position matched patching was rerun on alignment-validated pairs only (`*_aligned` groups). Last-position and non-verdict groups from the first run were unaffected.
* **Budget-driven reductions:** `num_rev` patching controls n = 6 (not 10), Stage 4 mixed controls n = 6, generation checks on 64 prompts per group.
* Direct head writes ≠ total importance; mean `z_h` may be out of distribution (hence resample); GQA: head ablation leaves shared K/V intact; the benchmark is re-created and form-determined; one direction at one layer; the selection S8 includes two heads with negative signed contributions (they are part of the frozen |Δ| rule); the confirmatory set was used for all reported criteria and k_a = 8 was fixed beforehand.
