# Phase 2.5 report — recompute diagnosis, source positions, and exploratory routing/content patching

**Status of earlier work (unchanged).** The Phase 2 preregistered verdict remains **mixed / inconclusive**, and the original attention-recompute gate remains **recorded as FAILED** (worst-case d_c-contribution error 2.7 % / 2.4 % of std at layers 19 / 22 vs a 2 % limit). No Phase 2 threshold or criterion was altered; the frozen S8 selection was not changed and no further heads were searched; no checkpoint, dataset or earlier result was modified. Everything below is a scoped amendment (`docs/phase25_plan.md`, Amendments 1 and 2, both committed before the corresponding results). Outputs: `results/phase25/`. Intervention results in this report are **exploratory**.

## 1. Diagnosis of the recompute discrepancy (conclusion: explained; it is bf16 rounding noise, not a defect of the recompute)

Findings:
* **Masking, GQA, RoPE, q/k normalisation are exact or negligible.** An independent SDPA call on the recompute's inputs reproduces the model to 1–2e-4 (the 1.6–1.8e-4 residual is bit-level kernel/batch nondeterminism); the GQA group loop is bit-identical to `repeat_kv`; fp32 RoPE changes the result by ≈ 0.1–0.2 %.
* **The gate discrepancy equals the bf16 output-quantisation floor.** Rounding an exact fp32 result to bf16 already produces a per-head-output relative error of 1.6–1.7e-3 (observed model-vs-recompute: 1.8e-3, i.e. ≈ 8–10 % above the floor; ≈ 85 % of the error variance is output rounding). The same floor has worst-case contribution errors of 1.7 / 3.0 / 2.6 / 2.1 / 2.8 / 2.9 % of std (L0/10/19/20/21/22): **no implementation that outputs bf16 head outputs could meet the original 2 % worst-case rule**; the rule was below the representable precision.
* **Error scale.** Normalised by the rms effect of independent rounding of each `z` element on the contribution (`2⁻⁹/√3·‖gain⊙z‖`), the observed error has rms ratio 1.6–1.7 (consistent with the true bf16 spacing) and a heavy tail (p99.9 ≈ 6, max 7–12), i.e. large only where `z` has a large norm but a small projection on d_c.
* **The recompute is not the less accurate path.** Against the FP32 reference the recompute and the model's SDPA output are equally far (≈ 1 % for layers ≥ 10; shared bf16 q/k/v rounding dominates) and the model's SDPA is closer to FP32 in only 48 % of the 100 worst cases. Casting probabilities to bf16 (as eager/flash-style kernels do) is **worse** than keeping them in fp32 (0.0025 vs 0.0018 from the SDPA output); HF eager is 7× further from SDPA than the recompute is.
* **Localisation of the 100 worst contribution errors:** layers 21 (39), 19 (34), 22 (14), 10 (11), 20 (2); heads L19H31 (19), L21H18 (15), L19H30 (14), **L22H5 (13)**, **L21H19 (13)**, L21H17 (11), L10H21 (8); **93 % at middle positions, 0 % at the first (sink) token, 7 % in the last five positions**; typical tokens are ordinary function tokens (` `, ` is`, ` if`, ` set`, `assistant`). 26 % belong to S8 (L22H5 and L21H19 only), but the S8 errors are small relative to those heads' own contributions (below).
* **S8 materiality** (recompute vs model SDPA, errors ÷ the head's own contribution std): RMS 0.15–0.21 % at all real positions, maximum 0.7–1.5 % (L22H5 1.52 %, L22H4 1.22 %); at the last token RMS 0.10–0.43 %, maximum 0.22–0.84 % (L22H5: max abs 0.0046 vs head std 2.50). So the failure of the original rule is driven by non-S8 heads with large output norms and small d_c alignment, and does not materially affect the important heads.
**Conclusion:** the discrepancy is explained (output rounding of the model's bf16 head outputs plus kernel-internal rounding); nothing remains unexplained that materially affects S8. Per the amendment conditions this permits exploratory patching under a newly justified criterion; the original gate stays recorded as failed.

## 2. Descriptive source-position analysis (model's own eager attention; custom recompute not used)
Method: attention weights from the model's eager attention, values from the model's `v_proj`, gains from `o_proj`; per-source contribution `A_{t,s}·(gain_h·v_s)` at the last query token; categories: first token (sink), chat prefix, instruction, rule / fact / conclusion (logic), body / question (localizer, PrOntoQA), final token of the last statement, template tail (generation-prompt tokens), self. Aligned valid/invalid pairs for logic (217 pairs → 434 prompts); 128 prompts each for the localizer and PrOntoQA. **Validation of the accounting identity:** the sum over sources reproduces the head contribution computed from the model's own SDPA output with correlation 0.997–0.9997 (logic), rms error ≤ 2.4 % of the head's std, class differences agreeing to ±0.003 (e.g. L22H5 +4.338 eager vs +4.339 SDPA); similar for the localizer and PrOntoQA. * **The verdict contribution of the positive S8 heads is read from the *summary positions* of the prompt** — the final token of the last statement and the generation-prompt tail — **not from the premises or the instruction** (instruction and rule contribute ≈ 0; the rule/fact lines 0–10 %). The two negative S8 heads (L22H8, L22H6) act through attention to the query token itself.
* **Attention mass barely differs between valid and invalid** at the contributing sources for logic (|Δmass| ≤ 0.03 at the top categories; L21H19 shifts 0.10 away from the tail for valid), whereas the signed value contributions differ strongly (e.g. L22H5 conclusion final token +0.38 vs −1.68). In the localizer, attention mass to the final body token differs by class (0.56 vs 0.32 for L22H5), so routing is more class-dependent there than for logic (not paired, hence not decomposed).
* **Symmetric accounting split of the aligned-pair difference (identity verified, max residual 1e-6; descriptive, not causal):** L22H5 +4.338 = routing **+0.173 (4 %)** + content **+4.165 (96 %)**; L21H19 +2.048 = +0.159 (8 %) + 1.889; L20H8 +0.685 = +0.003 + 0.681; L22H8 −0.546 = −0.002 − 0.543; the others ≥ 90 % content.
* **Cross-task:** same sources and same sign for the positive heads on all three tasks (summary positions); the layer-average of all 32 heads shows the same two sources (conclusion final token 49–56 %, tail 25–79 %) but with 30–400× smaller totals (+0.01 to +0.14), so S8 heads are not distinguished by *where* they look but by how strongly their values at those positions project on d_c.
* Eager-vs-SDPA: the descriptive analysis uses the eager weights (the only way to obtain the model's own weights); its per-example head contributions agree with the SDPA ones as stated above.

## 3. Validation under the new criterion (Amendment 2, fixed before any A/V result) and exploratory A/V patching
Validation: **V1 passed** (own SDPA call reproduces the model to ≤ 2e-4 rel. L2 at layers 19–22, limit 1e-3); **V2 passed** for all eight S8 heads (RMS ≤ 0.43 %, max ≤ 1.52 %; limits 1 % / 2 %); **V3 passed** (observed layer error ≤ 1.10 × the bf16 quantisation floor, limit 1.25; recompute vs FP32 ≤ 0.99 × the model's own error vs FP32, limit 1.05); **V4 passed** before any A/V effect was computed (self-patch of S8, L22H5, L21H19: max margin change 0.5–0.75 logits, mean 0.10–0.13, verdict changes ≤ 0.5 %, on 434 trials per format); **V5 passed** (A+V patch of S8 reproduces the model-native full-`z` patch to 4e-5 on `num_orig` and 1.8e-4 on `num_rev`, limit 0.05).

* **Value transport, not re-routing.** Replacing only the **attention weights** of S8 with the source's has no effect (T ≈ 0.01, indistinguishable from random heads), whereas replacing only the **values** reproduces essentially the entire full-head patch (0.89 of the margin gap; 0.94 of the verdict-coordinate gap; 94 % flips). A+V equals the full-`z` patch exactly, and the A×V interaction is ≈ 0 for all positions (a small positive +0.03–0.04 at the last position). The same holds for `num_rev` (so it is not the literal answer token), and for L22H5 alone (V-only 0.46/0.43, A-only ≈ 0). The descriptive accounting (96 % content for L22H5) and the causal V-only dominance agree.
* **Interpretation (cautious).** For these heads, what matters is the content of the **value vectors at the attended summary positions**, which already carries the verdict-related signal of the source example (consistent with Phase 0.6, where validity is linearly decodable at the conclusion's last token). The heads therefore *read out / transport* verdict-related content rather than *re-routing attention as a function of the verdict*. This does not show that the heads do not compute something in their OV circuits (the value contribution `gain_h·v_s` is the d_c-projection of values produced upstream), nor where the content at the summary positions is built. A prediction flip is not evidence of abstract logical content.
* The largest random draw reaches V-only transfer 0.109 (all positions), the same order as the random maximum 0.126 in Phase 2 (a draw containing an individually influential late-layer head); native S8 is ≈ 8× that.

## 4. Limitations
* The only way to obtain the model's own attention weights is eager attention, whose per-example head outputs differ from SDPA by ≈ 1.3 % (L2); the identity checks show the contribution profile is unaffected at the level reported (class differences agree to ±0.003).
* The V-only patch replaces values at **all** source positions; the descriptive analysis suggests the effect arises at the summary positions, but this localisation is not tested causally.
* Exploratory scope: 217 alignment-validated pairs (≈ half of the matched pairs; pairs whose sentences have different token lengths were rejected, which may favour some families), n = 10 random controls, no multiple-comparison framework; results cannot change the Phase 2 verdict.
* Categories are coarse; per-position (token-level) patterns within a category are not resolved; the localizer and PrOntoQA analyses are class-conditional, not paired.
* Values at the summary positions are computed by earlier layers; where they come from was not studied (outside scope).
* The new V1–V5 criterion was chosen after seeing the *diagnostic* (not the intervention) results; it is documented before the A/V results, but it is a post-hoc replacement for the original rule and is justified by the rounding-floor evidence above.

## 5. Recommendations
1. Keep the Phase 2 verdict and the failed gate on record; for future work specify head-output precision tolerances relative to the bf16 quantisation floor (RMS and last-token worst case per head) instead of an all-position worst-case rule.
2. If this line is continued: **position-restricted V-only patching** (values only at the conclusion's final token and the template tail vs. all other positions) to test the descriptive localisation causally; and a patch of the *residual stream* at those positions (upstream of the values) to see whether the verdict signal is produced there or supplied by earlier components.
3. Examine the downstream link suggested in Phase 2 (L22H5's output is read by the same layer's MLP; ablating it reduces the verdict-coordinate class gap by 11.9 versus 4.6 from its direct write) with a head → MLP-neuron mediation analysis (a new, separately preregistered study).
4. An fp32 (or higher-precision) re-run of the key head ablations is feasible for the S8 layers only (model weights in bf16 are the limit) and would bound numerical effects on the Phase 2 conclusions.
