# Phase 4 plan — upstream causal localization of the information read by the late S8 attention heads (PREREGISTRATION DRAFT, awaiting approval)

**Standing.** Plan only: nothing in this document has been implemented or run. Phases 0–3 (checkpoints, datasets, the frozen S8 set, the U22 ranking, all reports and all preregistered verdicts, including the Phase 3 **mixed** verdict) stay unchanged. The Phase 3 result is not described here as an isolated logic or verdict circuit: U22 mediation is established, verdict selectivity is not. No broad MVS optimization, neuron search or head search is part of Phase 4. Commits without co-author trailers; no push.

## 0. Central question and facts used (inspected in the repository)
**Question.** At which layers and token positions does verdict-related information become *causally available* to the late attention heads (S8: layers 19–22, jointly and S8_L22 / L22H5 separately)?

Facts relied on (all from committed code/results):
* Residual hook convention: index `i` = HF `hidden_states[i]` (`models/hooks.py`; `i=0` is the embedding output, `i≥1` is the output of `layers[i-1]`). Layer `l` reads `hidden_states[l]`, so a patch at index `i` can reach S8 heads in layers `≥ i`; at index 23 (output of layer 22, the verdict hook) **no S8 head can be affected** (negative control by construction).
* Prompt = `BASE + format tail + "\n\n" + syllogism` inside the chat template (`phase05.build_prompt`). The instruction therefore **precedes** the syllogism. Matched valid/invalid pairs (`phase05.build_pairs`) swap the roles of the same sentences (MP↔AC, MT↔DA), keep the same marker, and are kept only if token lengths are equal and the Phase 2.5 alignment rule passes (217 of 448 pairs on test contents → 434 trials per format, both directions).
* By causal attention, every position before the first differing token has an **identical residual** in source and target at every layer. Patching the chat prefix, first token and instruction is therefore an exact no-op; it can be used as an exactness test, not as a non-trivial control (see §3 for non-trivial "other position" controls).
* Phase 2.6 position groups (`heads/positions.py`): G1 = the `.` before `<|im_end|>` (1 token), G2 = the generation-prompt tail excluding the query (mean 8 tokens), Self = the query token, Remaining = all else. S8 value patching at G1∪G2 (9 of ≈87 positions) reproduced 0.90 / 0.92 of the all-position V-only transfer (`num_orig` / `num_rev`); G1 and G2 alone gave ≈0.25–0.32 each; their interaction was +0.21 to +0.24. That was *value-level, head-level* evidence of **sufficiency at the heads' inputs**; it says nothing about where those values are built.
* Phase 3: layer-22 MLP units mediate part of the S8_L22 effect (R_c≈0.61, R_m≈0.80), about 39 % of the coordinate effect bypasses them. Throughput measured in Phase 3: ≈140 sequences/s (batch 16, ≈87 tokens, Qwen3-8B bf16, RTX 5090). Content pool: 8 test contents, 4 validation contents (ordinary lexicon), 48 nonword-lexicon contents never used in any head/MLP experiment.

## 1. Definitions (fixed now; thresholds are not tunable from the pilot)
**Patch.** For an aligned pair (target `t`, source `s`, opposite labels; both directions are trials), position set `P` and hook index `i`: `h_t[P] ← h_s[P]` at `hidden_states[i]`, full residual vector (all 4096 dims), all other positions keep the target's values. Interpolated version `h_t[P] + α(h_s[P] − h_t[P])` for the dose-response diagnostics.

**Outcomes** (aggregated signed effects, as in Phase 3; sign `σ=+1` when the source is the valid member, so positive = toward the source):
* `T_m(i,P) = Σσ(Y_patch − Y_tgt) / Σσ(Y_src − Y_tgt)` for the answer margin `Y = logit(valid label) − logit(invalid label)` (valid label is `1` in `num_orig`, `2` in `num_rev`; the mapping is part of the token ids, so the same code covers both formats).
* `T_c(i,P)`: same ratio for the verdict coordinate `c = d_c · h_23[last]` (consensus verdict direction), reported as a *residual-coordinate outcome* and kept distinct from the margin.
* `T_h(i,P)`: same ratio for the **head readout** — the change of the S8 last-row verdict contribution `Σ_h (W_{O,h}ᵀd_c)·z_h` (per layer, S8_L22 and S8 jointly). This is the closest quantity to "available to the heads": it is measured at the heads' outputs, before MLP/late-layer amplification. Heads in layers `l > i` receive upstream changes both directly and via intermediate layers; this is reported as is, not decomposed.
* flip rate (`sign(Y_patch)` differs from target's), reported next to `T_m`.
* Denominators below the validity floor (margin gap < 10 logits, coordinate gap < 2.0 units, or noise-floor×3) make a ratio *undefined*, never imputed. Bootstrap replicates with an unstable denominator are discarded; >5 % discarded ⇒ undefined (the Phase 3 rule).

**Availability vs creation (the distinction this phase is built around).**
* *Availability* `A(i,P) := T(i,P)` — the residual at `(i,P)` is **sufficient**, with everything else left at the target's values, to move the heads' read-out/answer toward the source. A high value at `i` shows the information is present *in an accessible form* at `(i,P)`; a low value at `i` shows that the finished summary at `P` still depends on later computation that draws on un-patched positions/layers.
* *Necessity-side check* `N(i,P) := 1 − T(i, All∖P)`: how much is lost when everything except `P` is transplanted. It measures redundancy (other positions carrying the same information), not creation.
* *Creation / computation* is **not** established by availability. It requires component-level evidence about what *writes* the transferable content into `P` (Stage 4: attention-output vs MLP-output patches at `P` around the onset). Stage 4 identifies writers at the onset only; it is not a circuit trace, and the report will not claim that a layer "computes" the verdict. Statement templates fixed in advance: "available from layer L at positions P" (Stage 2); "reaches the heads through S8 / through other paths" (Stage 3); "written at P by the attention / MLP output of layer L" (Stage 4, exploratory).

**Onset layer** for a position set and format: with `T_plat := median_{i∈{19,20,21,22}} T_m(i,P)`, `ℓ_on :=` the smallest index `i≤22` such that the lower 95 % pointwise bound of `T_m(i',P)` is `≥ 0.5·T_plat` for **all** `i' ∈ [i,22]` (persistence). Also reported: half-rise index and saturation index (`≥0.9·T_plat`). The same definition is applied to `T_c` and `T_h`. No smoothing.

## 2. Data, splits, held-out status
* **Pilot (Stage 1):** the 4 validation contents (ordinary lexicon), `num_orig`, aligned pairs only. Used only to check feasibility, numerical tests, patch strength and cost; **no threshold, layer set, or condition may be changed from the pilot result**.
* **Confirmatory A (Stage 2–5):** the 8 test contents, 217 aligned pairs → 434 trials per format, `num_orig` and `num_rev`. *Disclosure:* these pairs were previously used in Phase 2.5/2.6/3 attention and mediation experiments (and are held out from the MLP ranking), so they are **not** fresh data; they give continuity and a direct comparison with Phase 2.6.
* **Confirmatory B (held-out replication, never used in any head/MLP experiment):** nonword-lexicon contents (up to 48), all 14 families, same pair construction and alignment rule, up to 400 trials sampled per format (stratified by family, deterministic seed). Reduced layer set and conditions (§6). Yield is measured in the pilot-time alignment census; if fewer than 150 aligned trials per format are obtained B is reported as underpowered, not substituted.
* Random controls use `crc32` seeds, recorded sets, and pools restricted to **non-summary, non-Self positions at or after the first token difference** (positions before it are exact no-ops and would make random controls trivially null and strength-mismatched).
* Statistics resample at the **pair level** (both directions of a pair kept together; 2000 resamples; matches the dependence structure better than the trial-level bootstrap of Phases 2.6/3). Because there are only 8 test contents, a **leave-one-content-out** range of every primary statistic is also reported; Confirmatory B (many contents) is the independent check on content generalization.

## 3. Experimental design
**Position sets** (all assigned from aligned token spans; masks identical for source and target or the pair is rejected, never realigned):
G1; G2; G1∪G2; Self; G1∪G2∪Self; Rule-body, Fact-body, Conclusion-body (the syllogism tokens before G1, split by `spans_logic` roles, excluding G1); Premise-region := Rule∪Fact; NonSummary := Remaining∖Self (all variable-region positions except G1, G2, Self); All; All∖(G1∪G2); All∖(G1∪G2∪Self); count-matched random sets (|G1∪G2| positions from the NonSummary pool, 3 draws in Stage 2, 5 in Stage 3); positions before the first difference (chat prefix, first token, instruction) as **exact no-op** controls (reported, expected T=0 exactly).
Non-trivial "other position" controls (instruction/prefix patches cannot be non-trivial within a pair):
* *Premise/conclusion-body controls* above (the positions that actually differ lexically between valid and invalid).
* *Format-mapping control (exploratory):* instruction-span residuals taken from the same syllogism in the **other** answer format (`num_orig`↔`num_rev`): tests where the label *mapping* (not the verdict) is read, separating "which side is valid" from "which token to emit". Reported only; not in the success criteria.
* *Same-label lexical control:* source = a different-content example with the **same** label (Phase 2.6 / `lexical_controls`), same positions and layers; expected flip rate near 0. Distinguishes verdict transport from lexical-content transport.
* *Norm-matched random-direction control:* replace `h_s[P]−h_t[P]` by a random direction with the same per-position norm; expected T≈0.

**Layers.** Confirmatory A: all hook indices 0…23 (24 values). Pilot: {0,2,4,8,12,16,18,19,20,21,22,23}. Index 23 = post-S8 negative control for the S8 route; index 0 patches the embedding output (token identity) and bounds the lexical contribution.

**Stages**
* **Stage 0 — tests and preflight (no experiment).** See §4.
* **Stage 1 — pilot** (validation contents, `num_orig`): conditions {G1, G2, G1∪G2, Self, NonSummary, All, All∖(G1∪G2), random×2}, pilot layers; patch-strength diagnostics; noise floor; one path check (freeze S8) at indices 16, 19, 22; alignment census for Confirmatory A and B. **Pilot gate (continue only if all hold):** all Stage-0 tests pass; `T_m(All)` equals 1 within the measured noise floor at every layer; no-op controls are inert; margin-gap denominator ≥ 10 logits and coordinate gap ≥ 2.0; cost per layer-condition within 1.5× the estimate (otherwise apply the degrade ladder §7 before continuing). A pilot with all `T_m(G1∪G2) ≤ 0.05` for `i ≥ 19` does not stop the study (it is a result), but triggers the minimal confirmatory set (G1∪G2, NonSummary, All, random) and the failure report.
* **Stage 2 — confirmatory layerwise availability** (Confirmatory A, both formats, 24 layers): the full position-set list above with 3 random draws; outcomes `T_m, T_c, T_h`, flip rate; G1 vs G2 vs G1∪G2 (separately and jointly) with the interaction `I(i)=T(G1∪G2)−T(G1)−T(G2)` (cluster-bootstrap CI), `N(i,P)` for the summary set, and onset layers with bootstrap CIs and leave-one-content-out ranges.
* **Stage 3 — path tests (does the upstream patch reach the answer through S8?)** at pre-registered indices: `ℓ_on` (per format), `ℓ_on−3`, `ℓ_on+3` (clipped to [0,22]), 19, 22 and 23. For P=G1∪G2 at all those indices, and P=G1, G2 at `ℓ_on` and 22. All freezes use the model-native `o_proj` pre-hook on the **last query row**, replacing `z` of the frozen heads with their value in the clean target run (so the freeze removes the head's *response* to the patch, not its existence). Conditions:
  1. total (no freeze);
  2. **freeze S8** (layers `≥ i`): remaining effect `T_noS8`; mediated share `M_S8 = 1 − T_noS8/T`;
  3. freeze **count-/layer-matched random non-S8 head sets** (8 heads in layers 19–22 with the same per-layer counts as S8; 5 draws): the share removed by a random set is the baseline for (2);
  4. freeze **all non-S8 heads in layers 19–22** (S8 live): `T_nonS8`;
  5. **S8-only path**: freeze every last-row head in layers `≥ i` except S8: `T_onlyS8` (sufficiency of the S8 route; the last-row MLPs and later layers stay live, so this still includes MLP amplification);
  6. freeze all **late (layers ≥ 23)** last-row heads: a path that bypasses S8 and the layer 19–22 stack;
  7. freeze **all** last-row heads at layers `≥ i`: for any non-Self patch this removes every attention route from the patched positions to the answer row and must give `T≈0` (exactness check of the freezing logic and of the claim that the effect travels by attention);
  8. the 2×2 of (freeze S8) × (freeze late heads) with interaction, because the routes are not assumed additive.
  Bypass `B = T_noS8/T`; shares are order-dependent when the interaction is large, so both `M_S8` (removal) and `T_onlyS8/T` (sufficiency) are always reported with the interaction, never a single "fraction through S8".
  Additional descriptive check in the same runs: S8 attention-weight change toward the patched positions vs value-content change is **not** decomposed (the Phase 2.5 recompute path is not reused; V1–V5 evidence stays as is).
* **Stage 4 — writers at the onset (exploratory, availability vs creation).** At `ℓ_on` and the three preceding indices (4 indices), patch separately the **attention output** and the **MLP output** of the layer that writes into `hidden_states[i]` at `P ∈ {G1, G2, G1∪G2}` (module outputs captured with the same hook-order machinery; accounting identity `h_out = h_in + attn_out + mlp_out` tested in Stage 0). Report `T_m` for each writer, their sum and interaction; no component below that level (no head or neuron search) and nothing at layers below `ℓ_on−3`. Statements are limited to "this layer's attention/MLP output at P carries transferable content".
* **Stage 5 — diagnostics and held-out replication:** dose-response (α ∈ {0.25, 0.5, 0.75, 1.0, 1.25}) at `ℓ_on` and 22 for G1∪G2 and a random set; same-label lexical, norm-matched random-direction and format-mapping controls at `ℓ_on` and 22; Confirmatory B on the reduced grid (indices {0,2,4,6,8,10,12,14,16,17,18,19,20,21,22,23}; conditions G1, G2, G1∪G2, NonSummary, All∖(G1∪G2), All, random×3; plus the S8 freeze at `ℓ_on`, 22).

## 4. Numerical correctness tests (required before any experiment; tiny-model fp32 where exactness is claimed, Qwen3-8B preflight where bf16 noise matters)
1. **Identity:** empty `P`, `α=0`, and source=target give logits equal to the clean run (within the measured noise floor on Qwen; exactly in fp32 tiny).
2. **Exactness of the positive control:** `All` patch at every index `i` reproduces the source logits (`T_m=1`) up to the measured bf16 floor; failure ⇒ stop.
3. **Causality:** (a) hidden states at layers `< i` are unchanged by a patch at index `i`; (b) positions before the first token difference have identical residuals and their patch is an exact no-op; (c) patching position `p` leaves positions `< p` unchanged at every later layer.
4. **Mask handling:** left-padding never selected; source/target masks identical; `check_groups` assertions hold per prompt; wrong shapes raise.
5. **Hook ordering** (Phase 3 `OrderLog` approach, recorded for every layer touched): the residual patch at index `i` precedes layer `i`'s `o_proj` pre-hook; freeze hooks (`o_proj` pre) at layers `≥ i` act before the layer's `down_proj`; capture of `z` for freezing is from a separate clean-target pass.
6. **Freeze mechanics:** freezing last-row `z` of any head set to its own clean values in an unpatched run is the identity; freezing at layers `< i` has no effect on a patch at `i`; freezing **all** last-row heads at layers `≥ i` makes any non-Self position patch inert (`|T|` within noise floor) — checked on tiny and on Qwen.
7. **Component accounting:** attention-output + MLP-output patch of layer `l` at all positions equals the residual patch at index `l+1`; individual component patches change only their own write.
8. **Interpolation:** `α` linear; `α=1` equals the patch.
9. **Batch invariance:** batch size 1 vs 16 logits agree within the noise floor (so batched and per-pair results are comparable).
10. **Statistics:** aggregated-ratio algebra; sign handling for the reversed format (valid-label token swap); bootstrap clusters keep both directions of a pair together; onset detection on synthetic monotone, noisy and non-persistent curves; leave-one-content-out utility.
11. **Controls:** random sets deterministic (`crc32`), size-matched, disjoint from G1/G2/Self and restricted to the variable region; norm-matched random directions have the exact per-position norm.
12. **Reproducibility/regression:** the existing 102 tests still pass; Phase 2.6's `All`-condition value-patch transfer and the S8 self-patch noise floors are re-obtained unchanged (no old artifact is rewritten).

## 5. Patch-strength diagnostics (reported with every curve; interpretation of a transfer ratio requires them)
Per index and position set: `‖h_s−h_t‖/‖h_t‖` (mean, distribution), absolute norm, fraction of the patch difference along `d_c` versus orthogonal, per-position share of the total patch norm, and the number of positions replaced. Transfer is also reported **against patch norm** (to separate "small patch, large effect" from "huge perturbation"). The massive-activation first token is never in a patch set (pre-difference no-op); the Self position, which holds an already-mixed residual late in the stack, is reported separately and not merged into "summary" results. The norm-matched random-direction control and the same-label lexical control calibrate how much transfer ordinary perturbations of equal size produce. The dose-response curve is checked for monotonicity (Spearman across α ≥ 0.9 required to interpret a linear transport story; otherwise reported as non-linear).

## 6. Preregistered criteria (apply to `T_m` primary, `T_c`/`T_h` supporting; both formats must satisfy each item; B is the replication check; failures are reported literally)
**Validity gate V0:** Stage-0 tests pass; denominators above the floors; exact controls inert; otherwise "not evaluable" and the phase stops.
* **A1 (summary availability):** `T_m(G1∪G2)` plateau `T_plat ≥ 0.50` and `T_c ≥ 0.50`, plateau over indices 19–22, lower 95 % bound ≥ 0.40.
* **A2 (localization to the summary positions):** at all `i ≥ ℓ_on`, `T_m(G1∪G2)` exceeds the max of the random count-matched draws by ≥ 0.30, random mean ≤ 0.10, and `T_m(NonSummary) ≤ 0.30`. If `T_m(NonSummary) > 0.30` the information is also available elsewhere ("distributed"; mixed).
* **A3 (upstream onset):** `ℓ_on` exists. *Upstream* means `ℓ_on ≤ 18` (information is available at the summary positions before the first S8 layer). `19 ≤ ℓ_on ≤ 22` means the summary positions become sufficient only inside the S8 layers (no separable upstream stage; reported as such, not as failure of A1). Onset difference between formats ≤ 2 layers (replicated); leave-one-content-out range of `ℓ_on` ≤ 3 layers; B reproduces `ℓ_on` within 2 layers (if B is evaluable).
* **A4 (separate vs joint):** classify with the Stage-2 curves at `i ≥ ℓ_on`: *joint-required* if `T(G1∪G2) − max(T(G1),T(G2)) ≥ 0.20` in both formats (Phase 2.6 saw +0.21 to +0.24 at the value level); *single-position sufficient* if `max(T(G1),T(G2)) ≥ 0.80·T(G1∪G2)`; otherwise *partial*. Onset order of G1 vs G2 is called only if the bootstrap CI of `ℓ_on(G2) − ℓ_on(G1)` excludes 0.
* **P1 (S8 route):** at `ℓ_on` and at 22, `M_S8 ≥ 0.40` for G1∪G2 in both formats, exceeding the random matched head-set removal (mean ≤ 0.15, max ≤ 0.30) with bootstrap CI of the difference excluding 0; freezing all last-row heads gives `|T| ≤ 0.05`. `0.15 ≤ M_S8 < 0.40` ⇒ *partial*. `T_onlyS8` is reported with the interaction and the late-head freeze; index-23 patches must show `M_S8=0` (exact, tested).
* **C1 (controls):** same-label lexical flip rate ≤ 0.10 and `|T| ≤ 0.10`; norm-matched random-direction `T ≤ 0.10`; dose-response monotone; no-op controls exactly 0.
* **Outcome table (mechanical):**
  * **SUPPORTED:** V0 ∧ A1 ∧ A2 ∧ A3 ∧ P1 ∧ C1 ⇒ "verdict-related information becomes causally available at the conclusion-final token and generation tail from layer `ℓ_on` and reaches the answer predominantly through S8", plus the A4 classification and, if `ℓ_on ≤ 18`, the explicit upstream localization.
  * **MIXED (named):** (a) A1 ∧ A2 but P1 partial or failed (other routes dominate); (b) A1 holds but A2 fails (distributed); (c) `19 ≤ ℓ_on ≤ 22` (emerges inside the S8 stack); (d) one format only, or B does not replicate; (e) A1 only for `T_c`/`T_h` but not `T_m` (or vice versa) — reported with which outcome fails.
  * **NOT SUPPORTED / NEGATIVE:** `T_m(G1∪G2) < 0.20` for all `i ≤ 22` (CI upper bound < 0.30), or not above the random controls, ⇒ summary-position residuals are never sufficient, and the Phase 2.6 value-level sufficiency is not reproducible at the residual level; reported as a negative result, and the next step would be the position-restricted *head-input* analysis rather than upstream tracing.
* Claim limits: the phase claims *causal availability* of information to the heads, never that it is "computed" at the onset, never that the pathway is verdict-specific (selectivity was not established in Phase 3 and is not re-tested here; the `d_c` coordinate is the shared accept/reject channel), and nothing about attributes of the full network beyond these 434/≤400 aligned trials per format.

## 7. Resource estimates, stopping rules, budget
Throughput ≈ 140 sequences/s (Phase 3). One full-model forward per patched condition (no mid-model start, to keep hook semantics identical).

| 0 | tests, preflight, noise floor | ≈ 10 k | ≈ 0.05 h |
| 1 pilot | ≈ 110 trials, 12 layers, ≈ 10 conditions + S8 freeze, census | ≈ 25 k | ≈ 0.12 h (incl. loading) |
| 2 | 434 × 2 formats × 24 layers × ≈ 13 conditions (incl. 3 random draws) | ≈ 270 k | ≈ 0.55 h |
| 3 | ≈ 13 freeze conditions × 6 indices (G1∪G2) + G1,G2 at 2 indices; 2 formats | ≈ 115 k | ≈ 0.22 h |

| | **total** | | **≈ 1.2 h (estimate ±30 %)**, hard cap **1.5 h** |
**Degrade ladder** (applied in order, recorded, never altering thresholds): random draws 3→2; Stage 2 layers on a stride of 2 for indices < 16 (full grid kept for 16–23); Confirmatory B trials 400→250; Stage 5 dose-response to one layer. The cap is enforced by per-stage time limits; GPU time is logged in `results/phase4/budget.json`.
**Stopping rules:** stop and report if V0 fails, `T_m(All)≠1` beyond noise at any layer, the pilot gate fails, the cap would be exceeded after the degrade ladder, or any unexpected inert/identity violation appears; Stage 3 runs only if A1 holds in at least one format (otherwise only the minimal path check); Stage 4 runs only if an onset exists and Stage 3 is evaluable; the study **stops after the report** — no upstream tracing below Stage 4's writer level, no head/neuron search, no MVS re-optimization.
