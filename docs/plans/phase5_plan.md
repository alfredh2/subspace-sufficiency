# Phase 5 plan: how does verdict-related information become available at the summary positions around layer 19? (PREREGISTERED; approved with 8 amendments, section 9, which take precedence over earlier wording)

**Standing.** Phases 0–4 (datasets, checkpoints, directions, the frozen S8 set and U22 ranking, all reports and all preregistered verdicts, including the Phase 3 and Phase 4 MIXED verdicts) stay unchanged. This phase is limited to the layer-19 onset; no full-layer or full-model search, no MVS optimization, no neuron search. Commits without co-author trailers; no push. Phase 4 did not show that layer 19 computes logical validity, and this phase does not assume it.

## 0. Facts used (inspected in the repository)
* Phase 4 (`docs/reports/phase4_report.md`): residual patches at G1∪G2 (conclusion-final token + generation tail, ≈9 positions) transfer 0.15 (hook index 19) → 0.62 (index 20, the output of layer 19) of the answer margin; the layer-19 **attention output** patched at G1∪G2 rows carries 0.36 / 0.39 (`num_orig` / `num_rev`), the layer-19 **MLP output** 0.04. Per-row-set: G1 rows 0.105–0.11, G2 rows 0.18–0.19; non-summary positions still transfer 0.35 at index 20. Patching the attention output of all heads at a row set is **identical to patching all 32 `z` heads at those rows** (`o_proj` is linear and bias-free), which gives an exact regression target for the new head-level code.
* Within layer 19, query rows do not influence each other: row r's attention output depends on the layer-19 *input* residual at keys ≤ r. The row-set interaction seen in Phase 4 (G1 0.105 + G2 0.18 vs joint 0.36) therefore arises **downstream of layer 19**, which is already a hint (not a conclusion) that downstream processing contributes to the apparent onset.
* Which heads: layer 19 has 32 query heads (8 KV groups of 4). Of the frozen S8 only **L19H10** is in layer 19 (Phase 2 last-row |Δ_h| = +0.30). Phase 2 listed several non-S8 layer-19 heads with |E_gap| 0.10–0.13 at the last query row. S8 was ranked by **last-row** writes into d_c; the Phase 4 effect concerns the **summary-row** outputs at layer 19 (rows G1 and the ≈8 tail rows), a different object. S8 heads at layers 20–22 (e.g. L20H8, L21H19, L22H5) then read the layer-19-modified residual at those positions from the last row.
* Infrastructure reused (validated in earlier phases): `heads/ablation.py` (`capture_z`, model-native `head_z_patch`, last-row or all-row), `heads/attention.py` (`recompute`, `attention_patch` with `v_positions`, `AttnStash`), `heads/positions.py`, `upstream/{patching,runner,data,stats,pipeline}.py` (position-set residual patch, component patch, last-row freeze with verification, aligned trials A/B/val, pair- and content-clustered bootstrap, onset logic). Phase 2.5 flagged **recompute errors concentrated at layer 19** (heads L19H30, L19H31 among the worst), so layer-19 recompute-based Q/K/V patching needs its own acceptance test (§5) before use.
* Throughput measured in Phase 4: ≈7.5 ms per full-model forward (133 sequences/s); set A = 434 trials per format (8 contents); set B (nonword, 43 contents) = 400 trials per format (frozen sampling); validation contents give 198 `num_orig` trials.

## 1. Language and levels of evidence (fixed now)
* **Descriptive attribution:** head output norms, attention mass, signed `d_c`-writes of head outputs, value-share decompositions. They show where a quantity is written, never what is causally used.
* **Causal influence:** the change in the answer margin / verdict coordinate after an intervention with explicit causal ordering (head output, value, attention weights, downstream pinning).
* **Information construction** is not established by any single measurement here. The attention output `z = Σ_k A_k v_k` is always a weighted sum of value vectors, so 'combination' is trivially true at the vector level. The operational distinctions used are in §3 (single-source sufficiency, complementarity beyond a one-dimensional downstream model, direct versus recomputation-dependent effect). Linear decodability is not used as evidence of use.
* The onset of causal *transfer* is not interpreted as the moment logical validity is computed; the report may state at most: 'which positions/heads supply transferable content', 'whether the effect depends on downstream recomputation', 'whether the layer-19 output alone, written into the residual, is sufficient'.

## 2. Definitions
* Matched pairs as in Phase 4 (equal length, Phase 2.5 alignment, validated token-span masks; both directions = two trials; `σ=+1` if the source is the valid member). Outcomes: answer margin `Y` (valid − invalid label logit), verdict coordinate `c = d_c·h_23[last]`, plus the new **local coordinate** `c20(R) = d_c·h_20` at the patched rows (index 20 = layer-19 output).
* Transfer `T = Σσ(Y_patch − Y_tgt) / Σσ(Y_src − Y_tgt)` (aggregated ratios, as before). Local transfer `L_c = Σσ·Δc20(R) / Σσ(c20^src − c20^tgt)` at the rows R. The immediate residual change at index 20 (`c20`, `w20`, relative change norm at the patched rows) is **reported separately from the final behavioral effect** `T_m`, `T_c`.
* **Rows R = G1∪G2** (primary), also G1 and G2 separately, NonSummary rows, Self row (controls). Layer 19 = `model.model.layers[19]`; head `z` patches use the `o_proj` pre-hook at that layer.
* **Intervention families on layer-19 heads H at rows R** (all model-native hooks unless stated):
  * **Z-patch:** replace `z_h` of heads H at rows R by the source's `z_h` (new `head_z_set_patch`: mask over rows; `head_z_patch` currently supports only all rows or the last row).
  * **V-patch / A-patch / AV-patch at key groups K** (recompute path, *delta form* `z' = z_native + [rec(patched) − rec(unpatched)]` so that the common-mode recompute error cancels; rows restricted to R, heads H, key groups K take source values and/or source attention weights; attention weights otherwise remain the target's).
  * **Key groups K** (from role spans; Phase 4 position sets): Rule, Fact, Concl (body), G1, G2 (as keys), Other (prefix/instruction/first token: identical in a pair, a no-op control), All.
  * **Downstream pinning:** after a layer-19 patch, the attention output and/or MLP output of layers 20..22 (variant: 20..35) **at rows R** are forced to the target's own clean values (`component_patch` with the target's captured outputs). The residual at R then equals target + the layer-19 write; later layers can still read it from the last row but cannot recompute at R. `S_pin = T_pinned / T_free`, the **fraction of the effect surviving summary-row pinning** (formerly called 'direct-write fraction'; pinning at R does not stop the answer-position row from reading the altered residual at R in layers 20+).
* **Selection data:** head subsets and thresholds are chosen on the **4 validation contents** (`num_orig`, 198 trials) only. Confirmatory set A = the 8 test contents (previously examined in Phases 2.5–4; disclosed), both formats. Replication B = nonword lexicon, 43 contents, frozen sampling (used in the earlier MVS research; independent of the head/MLP analyses; **not untouched**). B is run only after the A-based configuration is frozen by hash (as in Phase 4); nothing is tuned on B.
* Statistics for every ratio: pair-level and content-clustered bootstrap (2000 resamples), leave-one-content-out ranges; criteria are evaluated on **both** interval types (as in Phase 4). Multiple primary comparisons use Holm correction; empirical control ranks with ≥ 20 draws are reported with the p-floor 1/(n+1) noted, never as significance.

## 3. Hypotheses and how they are separated
Notation: heads H* = the head subset selected in Stage 1; R = summary rows.

* **H1 Transport.** Verdict-related content already exists in a source key group's value vectors (computed from `hidden_states[19]`), and layer-19 attention moves it into the summary rows.
  Predictions: (a) a large fraction of the effect survives summary-row pinning (**S_pin high**); (b) **one** source group K* reproduces most of the head-output effect when only its values are replaced (`F_K* = T_V(K*)/T_Z(H*,R)`); (c) attention-weight changes are minor (`F_A` small); (d) no complementarity: the remainder groups add ≈ nothing.
* **H2 Combination.** The effect needs content from *different* source groups (e.g. the fact-line and conclusion-line positions that actually differ between a valid/invalid pair), and the head output at R is a newly formed combination.
  Predictions: (a) S_pin high; (b) **no single group** reaches `F ≥ 0.5`, a **pair/triple** of groups does (`F ≥ 0.75`); (c) the pair effect exceeds what a one-dimensional downstream model predicts from the single-group effects (**residual interaction `I_res`** large). Because `Δz` is exactly additive over key groups when attention weights are fixed, any non-additivity in the *answer* must come from downstream nonlinearity or from a multi-dimensional dependence; the scalar-sufficiency test below separates these.
* **H3 Downstream amplification.** The layer-19 write is a relatively weak/low-dimensional signal at R; the Phase 4 'onset' largely reflects layers 20+ at R (and the last-row readers) amplifying it.
  Predictions: (a) **S_pin low**: pinning layers 20–22 (attention + MLP) at R removes most of the effect; (b) **local transfer `L_c` is small** relative to the final `T_c` (the verdict coordinate at R has not formed at index 20); (c) the head-output **dose-response is convex** (`g(0.5)/g(1)` well below 0.5; Phase 4 saw 0.19/0.62 for the residual patch); (d) a **scalar model** `T_K ≈ g(π_K)` (π_K = group share of the local readout, g = dose curve) predicts the group results without complementarity.
* **Scalar-sufficiency test (separates H2 from H3/H1).** (i) Measure the dose curve `g(α)`, α ∈ {0.25, 0.5, 0.75, 1, 1.25, 1.5}, for the full Z-patch of H* at R. (ii) For each key-group patch K compute its local readout share `π_K` (d_c, and the data-defined direction `w` = validation mean of σ·Δh20(R) normalised, fixed before test) and predict `T̂_K = g(π_K)`. (iii) `I_res = max over group sets (observed T − T̂)`. Small `|I_res|` ⇒ the non-additivity is explained by a one-dimensional downstream response; large positive `I_res` ⇒ complementary multi-dimensional content (H2).

## 4. Stages
**Stage 0 — implementation tests and preflight (§5).**

**Stage 1 — localize the layer-19 attention contribution (summary rows).**
1a. Selection run (validation, `num_orig`, 198 trials): single-head Z-patch (32 heads) at R; three rankings: **R1** causal (T_m of the single-head patch), **R2** descriptive local write `gain_h·Δz_h` at R (d_c-projection), **R3** the existing Phase 2 last-row |Δ_h| ranking (preserved). Nested top-k sets by R1 with k ∈ {1, 2, 4, 8, 16, 32}; `k*` = smallest k with `T_m(top-k) ≥ 0.8·T_m(all 32)` on validation. Fixed before test: H* = top-k* by R1; also R2-top-k* and R3-top-k* of equal size; the S8 member L19H10 alone; KV-group sets (four heads sharing a KV head) for the top group.
1b. Null sets (validation-derived matching): 20 random k*-subsets of the 32 heads; 20 **output-magnitude-matched** subsets (match the mean `‖W_{O,h}(z_s − z_t)‖` at R, computed on validation, by sampling heads in matched magnitude strata); the same top heads at the **non-summary rows** and at random row sets of equal size (row-specificity), and the Self row.
1c. Confirmatory evaluation (set A, both formats): all sets above plus all-32 (regression target: must reproduce the Phase 4 'attn19 at G1∪G2' 0.36 / 0.39 within 0.01) and single heads for the top-8 by R1. Outcomes `T_m`, `T_c`, `L_c`, flips. Rank agreement R1 vs R2 vs R3 (Spearman; descriptive attribution versus causal influence).

**Stage 2 — what supplies the content entering layer 19 (source positions).**
Recompute-path (delta form) patches for H*, the top-3 single heads, and 5 magnitude-matched random sets, at rows R: V-patch for K ∈ {Rule, Fact, Concl, G1, G2, Other, All} and pairs {Fact∪Concl, Fact∪G1, Concl∪G1, Concl∪G1∪G2, all-but-Fact...}; A-patch (source attention weights, target values) and AV for All and for the best group; descriptive attention mass of rows R on each group (target and source, with the model's own attention for the descriptive part). Outputs: `T_V(K)`, `F_K`, `F_A`, additivity of `Δz` over groups (exact check), local readout share `π_K`, and a comparison with the full residual patch of `hidden_states[19]` at K positions (Phase 4 'availability at the keys') to see whether the source representation is already causally sufficient before attention acts on it. Interpretation guard: a V-patch at K shows that the *source key representation* carries transferable content; it does not show who computed it.

**Stage 3 — transport vs computation (downstream recomputation and scalar sufficiency).**
3a. Fraction surviving summary-row pinning `S_pin`: Z-patch of H* (and all 32, top-1, random matched) at R with pinning of layers 20–22 {attention, MLP, both} at R (variant 20–35); also pinning combined with S8 last-row freezing (Phase 4 machinery) for the 'who reads the layer-19 write' question (descriptive).
3b. Local readout and amplification gain `T_c / L_c`; per-row-set (G1 rows vs G2 rows) comparison: since layer-19 rows are independent, the Phase 4 row interaction is attributed to downstream.
3c. Dose curve `g(α)` and the scalar-sufficiency test of §3 on the Stage-2 group patches.
3d. (Exploratory, only if 3a–3c are informative and budget allows) mismatched-content hybrids: Fact values from the valid sibling, Concl values from a same-label different-content example (relation-dependence of the combination).

**Stage 4 — validate the leading explanation.** Re-run the decisive subset (Z-patch sets, the best group V-patches, pinning, dose curve) on: set A both formats (primary), Replication B (nonword, both formats; configuration frozen first), the three held-out template families (reported separately from set A, no extra compute), same-label different-content lexical controls (`flip ≤ 0.10`), random head sets and random row/key-position sets (count-matched, ≥ 20 draws where cheap), norm-matched random-direction head-output patches. Report which findings generalize and which do not.

## 5. Numerical correctness tests (required before any experiment)
1. **Z-set patch:** empty rows/heads and source=target are the identity; `o_proj(z')−o_proj(z) = W_{O,H}Δz_H` exactly; all-32-head patch at R reproduces the Phase 4 component patch (`comp|attn|L19|G1G2`) bit-for-bit up to bf16 batching noise; rows outside R and heads outside H unchanged (tiny model exact, Qwen within the measured floor).
2. **Causality/ordering:** hook order (o_proj pre → attn out → local capture at index 20 → pins at layers 20+ → last-row readers), via the `OrderLog` approach; the patch changes `hidden_states[≥20]` only; layers < 19 unchanged; V-patch keys later than a row have no effect on that row.
3. **Delta-recompute acceptance for layer 19:** (a) null patch ⇒ `z' == z_native` exactly; (b) AV-all-keys-all-heads at R equals the model-native Z-patch of the same heads within the self-patch noise floor, margin transfer within 0.03; (c) per-head recompute error ≤ 1% RMS of the head's own `z` std at R (the Phase 2.5 V2-style criterion) — heads failing (c) (e.g. L19H30/31 if selected) are excluded from V/A/AV analyses and reported; (d) `Δz` exactly additive over disjoint key groups at fixed attention weights (fp32 tiny exact; Qwen within the floor).
4. **Pinning mechanics:** pinned components at R equal the target's clean outputs (direct comparison, maximum difference reported), unpinned rows/layers unchanged, pin without patch is the identity, pin of layers beyond the readout does not affect earlier hidden states.
5. **Position and role masks:** Fact/Concl/Rule/G1/G2/Other partition the eligible positions per prompt; the positions where source and target tokens differ lie only in the Fact and Concl line spans (counts reported); masks identical for source and target; no padding selected; Other is an exact no-op.
6. **Stats/analysis code:** group-share arithmetic, scalar-model prediction on synthetic dose curves with known additive/nonadditive structure, pair/content bootstrap clustering, magnitude-matched sampler determinism (`crc32` seeds) and disjointness of selection (validation) from evaluation (test) data.
7. **Regression/pilot gate:** all-32 Z-patch at R reproduces 0.36 / 0.39 (±0.01); residual patch at index 20 reproduces 0.62 / 0.63; Phase 4 pinned/frozen verification tests still pass; the existing 115 tests pass.

## 6. Preregistered quantitative criteria
All thresholds are prespecified **effect-size targets** on answer-margin transfer, applied to set A in **both** formats, on pair-level and content-clustered 95% bounds, and checked on B; they are not universal criteria for when computation begins or whether an attention pathway is necessary. Failed validity (V0) ⇒ not evaluable.
* **C (head concentration):** `k* ≤ 4` and `T_m(top-k*) ≥ 0.70·T_m(all 32)` on test (lower bound ≥ 0.60), with random and magnitude-matched null means ≤ 0.15·T_m(all 32) and the best null draw ≤ 0.30·T_m(all 32). Otherwise the effect is **distributed**; Stages 2–3 then run with the all-32 set (declared fallback). Causal ranking R1 vs descriptive R2 vs existing R3 agreement is reported; disagreement is a finding, not a failure.
* **Fraction surviving pinning `S_pin`** (H*, R, layers 20–22 pinned, attention + MLP): *high* if `S_pin ≥ 0.50` (lower bound ≥ 0.40); *low* if `S_pin ≤ 0.30` (upper bound ≤ 0.40); otherwise *intermediate*. A high `S_pin` is not evidence that layer 19 computes the verdict.
* **Local transfer ratio** `ρ = L_c / T_c` (verdict coordinate at R after layer 19 relative to the final coordinate transfer): *direct verdict write* if `ρ ≥ 0.40`; *weak local signal* if `ρ ≤ 0.25`.
* **Single-group sufficiency:** `F_K ≥ 0.60` (lower bound), with attention-weight share `F_A ≤ 0.20`.
* **Complementarity:** no single group with upper bound `F_K ≥ 0.50`; some pair/triple with `F ≥ 0.75`; `I_res ≥ 0.15` (lower bound > 0.10).
* **Scalar model fits** if `max |T_K − g(π_K)| ≤ 0.10` over all group patches; **convex dose** if `g(0.5) ≤ 0.40·g(1)`.
* **Controls (V4):** random heads, magnitude-matched heads, random rows/keys: mean ≤ 0.15·reference, max ≤ 0.30·reference; same-label lexical flip rate ≤ 0.10; norm-matched random-direction head-output patch `T ≤ 0.10`; Other/pre-difference exact zero.
* **Outcome table (mechanical):**
  * **H1 TRANSPORT supported:** V0 ∧ S_pin high ∧ ρ ≥ 0.40 ∧ ∃ K* with single-group sufficiency ∧ ¬complementarity ∧ controls ∧ replicates in the second format and B. Report as 'attention moves existing source value content into the summary rows', *not* as a computation of validity.
  * **H2 COMBINATION supported:** V0 ∧ S_pin high ∧ ρ ≥ 0.40 ∧ complementarity ∧ ¬(scalar model fits) ∧ controls ∧ replication.
  * **H3 AMPLIFICATION supported:** V0 ∧ S_pin low ∧ ρ ≤ 0.25 ∧ scalar model fits ∧ convex dose ∧ controls ∧ replication. Report as 'the layer-19 output is a weak/low-dimensional signal amplified by layers 20+', with the single-group results descriptive only.
  * **MIXED (named):** transport + amplification (S_pin intermediate), single group `0.5 ≤ F_K < 0.6`, a hypothesis supported in only one format or only on pair-level bounds, B fails to replicate, distributed head set (C fails) with the all-32 fallback otherwise meeting a hypothesis' criteria.
  * **INCONCLUSIVE:** V0 or the delta-recompute acceptance (§5.3) fails for the selected heads (Stage 2 then limited to model-native Z/pin results), denominators below the floors (margin gap < 10 logits, coordinate gap < 2.0), or interval widths exceeding the thresholds' margins.
  * **NEGATIVE for layer-19 attention as the locus:** `T_m(all 32 Z-patch)` fails to reproduce ≥ 0.25 on the confirmatory set, or no head subset beats the magnitude-matched null.

## 9. Approval amendments (binding; they supersede earlier wording)
1. **Pinning terminology.** D19 is renamed `S_pin`, 'fraction of effect surviving summary-row pinning'. Pinning layers 20–22 at the summary rows does not block later answer-position attention from reading the altered residual states at those rows, so `S_pin` is not a 'direct write' and not proof that layer 19 computes the verdict. The immediate residual change at index 20 (`c20`, `w20`, relative norm) is reported separately from `T_m` / `T_c`.
2. **Scalar-sufficiency test frozen on validation.** The scalar direction `w` (validation mean of σ·Δh20 at R, normalised), the dose-response mapping `g` (monotone interpolation of `T_m` against the measured local scalar share π(α), α ∈ {0.25, 0.5, 0.75, 1, 1.25, 1.5}, fitted on **validation trials only**) and every fitted parameter are written to `results/phase5/selection.json` and committed before any held-out evaluation. Predictions `T̂_K = g(π_K)` are evaluated on set A (both formats) and B; **prediction errors are reported per key group**, together with two simple alternative baselines fixed in advance: (i) proportional `T̂_K = π_K` (no curvature), (ii) the same construction with `d_c` replacing `w` as the scalar. Agreement of the scalar model is evidence *consistent with* one-dimensional amplification, not proof that the mechanism is one-dimensional.
3. **Head selection preserved.** Heads are ranked by individual causal transfer on validation (R1). The nested top-k sets are frozen from that ranking; the **full top-k curve (k = 1…32)** and the **eight KV-group comparisons** are reported on validation and on held-out data. If the individual-head ranking fails (no small k* reaches the target), no alternative subset is optimized on held-out results; the declared all-32 fallback is used and the failure is reported.
4. **Unambiguous inequalities.** A criterion stated on a point estimate says so; a criterion stated on a bound refers to the stated end of the 95 % interval. Complementarity: **for every single key group K, the upper 95 % bound of `F_K` is < 0.50**, and some group set has point `F ≥ 0.75` with lower bound ≥ 0.65, and `I_res` has point ≥ 0.15 with lower bound > 0.10. Single-group sufficiency: lower bound of `F_K*` ≥ 0.60 and upper bound of `F_A` ≤ 0.20. Direct-vs-pin: `S_pin` high = point ≥ 0.50 and lower bound ≥ 0.40; `S_pin` low = point ≤ 0.30 and upper bound ≤ 0.40. Local ratio: `ρ` high = point ≥ 0.40 and lower bound ≥ 0.30; `ρ` low = point ≤ 0.25 and upper bound ≤ 0.35. Scalar fit = per-group |error| point ≤ 0.10 and upper bound ≤ 0.15 for every group. Convex dose = `g(0.5)/g(1)` point ≤ 0.40 and upper bound ≤ 0.50. Controls: means ≤ 0.15·reference and the largest draw ≤ 0.30·reference (reference = the all-32 Z-patch effect), lexical flip rate point ≤ 0.10, norm-matched random-direction `T` point ≤ 0.10.
5. **Few independent contents.** Pair-level and content-clustered intervals are reported, and **leave-one-content-out stability is the emphasized check** for set A (8 contents): a set-A criterion counts as met only if its point-estimate inequality also holds in every one of the eight leave-one-content-out recomputations (and in both formats). Set B (nonword) is a **replication with documented prior exposure** (its items were used in the earlier MVS research), not an untouched test set.
6. **Hypotheses are non-exclusive.** Each hypothesis (H1 transport, H2 combination, H3 amplification) is scored separately as supported / partially supported / not supported / inconclusive from its own criteria; the outcome is reported as the **mixture**. The 'intermediate' `S_pin` range (0.30–0.50) is reported as 'transport or combination with a substantial recomputation-dependent component', with the shares `S_pin` and `1 − S_pin` and the group results side by side; H1 and H2 exclude each other only within one head set and row set (single-group sufficiency vs complementarity), not across heads/rows. A late causal-transfer onset is **not** interpreted as the moment logical reasoning is computed.
7. **Validation gates kept.** The model-native all-head Z-patch regression (0.36 / 0.39 ± 0.01), the delta-recompute acceptance, hook ordering, exact source-position alignment and pinning verification are required before the corresponding experiments. If recomputation fails for important heads, only validated model-native interventions (Z-patch, pinning, dose-response, row/head controls) continue and the Stage 2 conclusions are limited accordingly.
8. **Compute.** The 3–4 GPU-hour soft budget stands; extensions are justified in the report. Stopping is by scientific criteria (§7), not by a rigid runtime limit.
