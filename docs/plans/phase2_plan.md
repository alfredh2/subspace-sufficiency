# Phase 2 plan — attention-head contributions to the consensus *verdict direction*

**Terminology (binding):** the target is the *verdict direction* `d_c` (consensus rank-1 direction, hook `residual_index 23` = output of `layers[22]`), an accept/reject verdict channel shared by logic, the language localizer and PrOntoQA. It is **not** an abstract-logic circuit; no claim about "logic heads" is made.
**Status of earlier work:** Phase 0–1 artifacts, checkpoints, datasets and the Phase 1 verdict (**mixed / inconclusive**, frozen criteria) are read-only and unchanged. Phase 2 may strengthen the mechanistic picture but does not re-open Phase 1's criteria. Outputs: `results/phase2/`. Nothing is pushed; no co-author trailers.
**This document is committed before any Phase-2 result exists. Numerical thresholds are preregistered targets; later changes are dated amendments.**

## 0. Facts used (inspected, not assumed)
Qwen3-8B: 32 query heads, 8 KV heads (query heads 4j..4j+3 share K,V of KV head j), head_dim 128, **no attention bias** (`o_proj` has none; the reconstruction test still includes a bias term), per-head RMSNorm on q and k before RoPE, no sliding window; the input of `o_proj` is the concatenation of per-head outputs `z_h`, head h at `[128h, 128h+128)`. Phase 1 Stage 1: attention supplies +8.54 of the +19.2 class difference of `c = d_c·h₂₃` with almost no cancellation across layers (Σ|·| = 8.56), concentrated in layers 22 (+4.88), 21 (+2.28), 20 (+0.82), 19 (+0.46). One Phase-1-style evaluation condition costs ≈14 s.

## 1. Definitions
* **Head contribution** at the last prompt token (primary position; conclusion-end secondary): `s_h = (W_{O,h}ᵀ d_c)·z_h`; class difference `Δ_h = E[s_h|accept] − E[s_h|reject]` (semantic labels: logic valid/invalid, localizer English/nonsense, PrOntoQA true/false). Concentration uses `|Δ_h|` only; signed `Δ_h` is used for reconstruction/cancellation only.
* **Margin class gap** for task T: `G_T(S) = mean margin(accept) − mean margin(reject)`, margin = accept-label logit − reject-label logit (semantic, per format). Raw signed reduction `R_T(S) = G_T(∅) − G_T(S)`; reference `R_T(dc)` for ablating `d_c` with the Phase-0 operator.
* **`E_gap^T(S) = R_T(S) / R_T(dc)`** (signed; negative values mean the intervention *increases* separation). It is **undefined** unless `R_T(dc) ≥ 10` logits (so logic `num_orig`, `num_rev` and the localizer are defined; PrOntoQA, whose `R(dc)` ≈ 4.6, is undefined and reported only through raw reductions). Raw margin differences are always reported next to every ratio; bootstrap replicates with a denominator < 5 logits are discarded and counted.
* **Native heads vs rotated blocks.** A native head is the model's own 128-dim partition of the pre-`o_proj` space. A *rotated block* is a 128-dim block of `R z` for Haar `R ∈ O(4096)` (with `W_O → W_O Rᵀ`, function-preserving) or of a random coordinate permutation; these are alternative coordinate decompositions of the same update, **not independent computational heads**. Native-vs-rotated concentration (geometry) is evaluated separately from the causal importance of native heads (interventions).

## 2. Stage 0 — infrastructure and tests (before any result)
Modules: `src/causal_subspaces/heads/` (decomposition pass, head-level ablation/patching hooks, attention recompute, alignment validation, nulls, evaluation helpers), tests, scripts `phase2_*.py`.
**Tests (all required):**
* Head decomposition: `Σ_h W_{O,h} z_h (+ bias) = attention output` (fp32 exact on tiny model; bf16 tolerance on Qwen), GQA mapping (query head h ↔ KV head ⌊h/4⌋), per-head contributions sum to `d·attn_out`.
* Ablation hook ≡ manual surgery of the `o_proj` input; `k = 0` no-op; layer ≥ 23 rejected; self-patch no-op; z-patch coordinates; direct-change identity for the last layer before the hook.
* Attention recompute (tiny model, fp32 exact; **real Qwen3 batches, see gate below**): equals the original attention output including padding, GQA, q/k norm and RoPE; attention rows sum to 1 and are causal.
* **Patch identity (corrected):** recomputing a head with **both** source attention weights and source values reproduces the *source* head output exactly; `z(A_t,V_t)` reproduces the target; the 2×2 interaction term `z(A_s,V_s) − z(A_s,V_t) − z(A_t,V_s) + z(A_t,V_t)` is computed and reported, and **A-only and V-only effects are not assumed additive.**
* Symmetric routing/content decomposition identity (below) verified numerically.
* Haar-block / permutation nulls are orthogonal, function-preserving (`W_O Rᵀ R z = W_O z`), seed-reproducible; layer-mass matching rescales as defined; `|Δ|` metrics on closed forms; matched-control samplers; empirical-p / Holm helpers.
* Regression: the intact and `d_c`-ablation conditions recomputed on the Phase-1 exploratory evaluation subset reproduce the Phase-1 stored margins within bf16 tolerance.

**Recompute gate (hard gate for all routing/content/A-V work).** On real Qwen3-8B padded batches (16 prompts of varying length from logic, localizer and PrOntoQA), for layers {0, 10, 19, 22}: relative L2 error between recomputed and original per-head outputs `z` ≤ 0.02 (median ≤ 0.005), recomputed `d_c`-contribution error ≤ 2 % of its std, attention rows sum to 1 ± 1e-3, and agreement with the model's eager attention path (when switchable) within the same tolerance. **If the gate fails: routing/content analysis and A-only/V-only patching are cancelled; the simpler head-output decomposition, ablations and full-z patching continue.**

## 3. Stage 1 — head decomposition (all 23 × 32 = 736 heads)
* **Data.** Ranking on training prompts only: logic 1000 (balanced, train contents/families, `num_orig`), localizer 256 and PrOntoQA 256 (generator seed 101). Held-out confirmation on the Phase-1 held-out logic splits (768) and seed-0 controls.
* **Reported:** per-layer and pooled signed and absolute `Δ_h` for every head (ranked by layer and globally), top-k mass shares for k ∈ {1,2,4,8,16,32,64}, `N_eff`, Gini, signed top-k reconstruction of the held-out net attention class difference, per-example R², cancellation (class-level κ, per-layer, per-example). Logic/localizer/PrOntoQA separately; cross-task Spearman and top-k overlap vs hypergeometric expectation.
* **Concentration nulls** (separate families, never pooled), all **layer-matched**: (i) *Haar-rotated 128-dim blocks* within each layer (true Haar n = 20 per layer + the exact two-vector sampler n = 1000; sampler validated vs true Haar by KS); (ii) *random coordinate permutation blocks* within each layer; (iii) *head-shuffled alignment* (permute the per-head gain slices among the heads of the same layer).
* **Layer matching (amendment).** Report (a) within-layer concentration (top-2 share and `N_eff` over the 32 heads of each layer; mass-weighted mean over layers 19–22), and (b) a **layer-mass-matched pooled** statistic: every null layer vector is rescaled to the native layer's total `Σ|Δ|` before pooling, so pooled differences reflect within-layer specialization and cannot be produced by concentration in the last layers. The unmatched pooled numbers are shown for completeness but are not used in any criterion. Also pooled over layers 0–18 and 19–22 separately.
* **Gate S1:** continue only if identity passes, split-half Spearman of `|Δ_h|` ≥ 0.5, and the absolute attention share of total writes ≥ 0.15. Else report descriptively and stop.

## 4. Stage 2 — analysis of the important heads (frozen selection)
* **Frozen sets** (training ranking by `|Δ_h|`, pooled): **S8** (primary, `k_a = 8`), **S16** (secondary); fixed before any causal run.
* **Source-token analysis** (needs the recompute gate): attention mass and value-contribution mass by source category (instruction, rule, fact, conclusion, chat-template, final prompt tokens, first-token sink), per class, with attention entropy. Causal token positions and masks come from the recompute path built from the 2D attention mask (not HF internals). Attention weights are descriptive only.
* **Symmetric routing/content decomposition.** For an aligned valid/invalid pair at the last position with per-source scalar value projections `u_s = (W_{O,h} v_s)·d_c` and attention weights `A_s`: `c(v) − c(i) = Σ_s (A^v_s − A^i_s)·ū_s  +  Σ_s Ā_s·(u^v_s − u^i_s)`, with `ū = (u^v+u^i)/2`, `Ā = (A^v+A^i)/2` (exact; verified numerically; sum of the two terms equals the pair difference). The terms are an accounting identity, **not** independently causal. Frozen classification of a head (on train-content pairs, confirmed on test-content pairs): routing-dominant if |routing|/|content| > 2, content-dominant if < 0.5, else mixed; it remains tentative until the Stage 3 A-only/V-only patch effects (and their interaction term) are consistent.
* **Alignment validation (amendment).** A pair is *valid* for any all-position, attention-weight or value patch and for routing/content only if: equal total token length; identical token ids in the shared prefix (chat prefix + instruction + rule line); the fact line and the conclusion line occupy **identical token spans** in both prompts (so the same role sits at the same position and RoPE positions agree); identical final template tokens; identical padding layout when batched (source and target batches are built from equal-length pairs in the same order). Invalid pairs are **rejected and counted**, never aligned heuristically; last-position full-`z` patches need only the identical final template tokens. The number of valid/rejected pairs is reported.

## 5. Stage 3 — causal experiments
* **Evaluation sets.** *Exploratory* = Phase-1 subset (regression check only). *Confirmatory* = the complementary 384 held-out logic examples (64/64 per split-class) + fresh seed-5 localizer, PrOntoQA, MMLU-binary, Stroop, word-recall items + the 32 unused WikiText passages. **All preregistered criteria are evaluated on the confirmatory set;** `k_a = 8` is fixed now. Intact, `d_c`-ablation, MLP-only and combined conditions are all re-run on this same set with the same denominator.
* **Interventions** (on `z_h` before `o_proj`): mean replacement (neutral-corpus mean of `z_h` over all positions) primary, all positions; secondary: last position only, zero replacement, and resample replacement (value of the next prompt in the length-sorted batch at the same right-aligned position), for S8/S16.
* **k grid** {1,2,4,8,16,32,64} with the frozen `|Δ_h|` ranking; k = 1 ablates every head of layers 19–22 (128 conditions) as a head-effect map. **Alternative rankings:** signed `Δ_h`, output-magnitude-only (`E‖W_{O,h} z_h‖`), localizer-ranked, PrOntoQA-ranked.
* **Controls per k:** random heads (layer-count matched), layer-restricted random heads (from layers 19–22), output-magnitude-matched heads (same layer, nearest `E‖W_O,h z_h‖`), alignment-matched heads (nearest `‖W_{O,h}ᵀ d_c‖`).
* **Draws and significance resolution.** k = 8: **30 draws per family** (120 controls); k ∈ {2,4,16,32}: 10 per family (random, layer-restricted, magnitude-matched), effect sizes only; k = 64: 5 per family. With n = 30 the smallest attainable one-sided empirical p is **1/31 = 0.032**; with 4 control families × 2 formats = 8 primary comparisons, a Bonferroni/Holm threshold of 0.05/8 = 0.006 **cannot be reached by empirical p alone**. Therefore: "exceeds every sampled control draw" is a necessary condition, reported with its p resolution and **not** presented as significance; the decision statistic is a Holm-corrected (over the 8 comparisons) one-sided test on the z-score `(E_native − mean_ctrl)/sd_ctrl` with a Shapiro check of control normality (empirical fallback if rejected), together with the bootstrap (over eval examples) CI of `E_native − mean_ctrl`. Claims are worded accordingly.
* **Metrics, reported separately:** (a) *direct* head-write change of `c` (`−Σ(z_h−z̄_h)·gain_h`), (b) *actual* change of `c` at the hook after recomputation (capture hook registered **after** the intervention hook), (c) answer-level: raw margin gap/shift, `E_gap`, AUC, P(accept), invalid rate; verdict-free shifts (MMLU, Stroop, word recall); WikiText KL; **generation checks** at S8/S16/`d_c`/intact: greedy first-token invalid and constant-answer rates, 8-token greedy continuations on 64 prompts per group (fraction identical to intact) and 1-digit multiplication accuracy.
* **Counterfactual patching** of S8 outputs on aligned matched pairs (both directions, `num_orig` and `num_rev`, test contents, plus the invalid-pair accounting above): full-`z`; A-only (source weights, target values); V-only (target weights, source values); A+V (must equal full-`z`); all positions and last position. The interaction term of A/V is reported. Controls: random / layer-restricted / magnitude-matched heads (n = 30), same-label lexical controls, unmatched last-position patches on MMLU/Stroop/word recall. Direct (immediate change of `c`) vs downstream (after recomputation) reported separately. A prediction flip is not evidence of abstract content.
* **Gate S3** (after the head-effect map, S8 with controls): if `E_gap(S8) < 0.05` (logic `num_orig`) and S8 does not exceed the control maxima → stop with a minimal patching run, skip Stage 4; if in [0.05, 0.15) → Stage 4 limited to S16+MLP-512; if ≥ 0.15 → full plan.

## 6. Stage 4 — attention + MLP (conditional on Gate S3)
Conditions on the **same confirmatory examples and the same `R_T(dc)` denominator**: attention-only (S8, S16), MLP-only (top-64 and top-512 units from Phase 1), combined (S8+512, S8+64, S16+512), full `d_c` ablation, generic combined controls (random heads + random units, n = 20 of the same counts), and an upper-bound reference (all heads and all units of layers 19–22 mean-ablated). Effects are consistently normalized signed `E_x = R(x)/R(dc)`; interaction `I = E_comb − E_a − E_m`, with a paired bootstrap over examples. **Classification (amendment):** a CI containing 0 is **not** evidence of additivity. *Equivalent to additivity* only if the 90 % CI of `I` lies inside ±0.10 (equivalence test); *sub-additive/redundant* if the 95 % CI lies below 0; *super-additive/interactive* if above 0; otherwise *compatible with additivity but inconclusive*. Gap closure: `E_comb ≥ 0.80` closes, 0.5–0.8 partially, < 0.5 does not; remaining verdict-coordinate class gap reported.

## 7. Preregistered criteria (confirmatory set; targets, no forced binary)
* **H-geometric:** layer-mass-matched pooled top-8 share ≥ 2× the Haar-block null mean and above all 20 true-Haar draws, `N_eff` ≤ 0.5× null, same relation to the permutation-block null; within-layer top-2 share and `N_eff` for layers 19–22 reported with the same ratios; signed top-8 reconstruction ≥ 50 % of the held-out net attention class difference, per-example R² ≥ 0.5, random-8 < 10 %.
* **H-causal (S8):** `E_gap` ≥ 0.20 on logic `num_orig` **and** `num_rev` (defined denominators); Holm-corrected z-test vs each of the four control families (8 comparisons) and bootstrap CI of the difference excluding 0, and exceeding all sampled draws (necessary, not sufficient); ≥ 0.10 above the output-magnitude-only ranking; WikiText KL < 0.02 and verdict-free shifts < 1 logit (a narrow miss is a failure, with context reported); direct and actual changes of `c` have the same sign.
* **H-patching:** full-`z` transfer ≥ 0.10 (`num_orig`, valid aligned pairs) with random heads |transfer| < 0.02 and non-verdict tasks |transfer| < 0.05; routing/content labels count only if the recompute gate passed and the A/V patch results (with interaction) agree with the decomposition thresholds.
* **Overall (mechanical):** *sparse head implementation supported* only if H-geometric, H-causal and H-patching all hold; *distributed* if top-8 share < 1.5× null and `E_gap(S8)` < 0.05 and `E_gap(S64)` < 0.10; every other outcome is reported as **mixed / inconclusive with the named pattern**. Separately: "combined components explain substantially more of the verdict-channel effect" is judged by `E_comb` vs `max(E_a, E_m)` on the same denominator, with the interaction class above.

## 8. Stopping rules and budget
Stage 0 tests and the recompute gate before results; Gate S1; Gate S3; hard cap **4 GPU-hours** for Phase 2 (tracked in `results/phase2/budget.json`); no exhaustive run is launched; results (including negative ones) are kept.

## 9. Resources (RTX 5090)
VRAM ≈ 17–18 GB peak (model + batch-32 hooks; attention-weight tensors for a few layers < 100 MB); Stage 1–2 ≈ 25 min; Stage 3 ≈ 1.7 h (~430 conditions × 14 s) + ≈ 40 min patching; Stage 4 ≈ 35 min; total ≈ 3.3 h; storage < 150 MB (compressed per-example arrays).

## 10. Limitations carried into reports
Direct head writes ≠ total importance (later attention/MLP recompute); mean `z_h` can be out of distribution (hence resample); GQA: query-head ablation leaves shared K/V intact, and the value for a head is its KV group's; attention weights are not explanations; patch pairs are restricted to the aligned subset; the benchmark is re-created and form-determined; one direction at one hook layer, read at the answer position; multiple comparisons are handled as stated, with limited empirical-p resolution.
