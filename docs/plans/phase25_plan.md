**Status of Phase 2.** Preserved unchanged: the preregistered Phase 2 verdict is **mixed / inconclusive**; the original attention-recompute gate is recorded as **FAILED** (worst-case d_c-contribution error 2.7 % / 2.4 % of std at layers 19 / 22 vs the 2 % limit); no Phase 2 threshold or criterion is altered. Outputs go to `results/phase25/`. Nothing is pushed; no co-author trailers.

## Procedure (in this order)
1. **Diagnose the worst-case recompute errors** (`scripts/phase25_diagnose_recompute.py`). On real padded Qwen3-8B batches, for layers 0, 10 and the S8 layers 19–22: compare the custom recompute (fp32 attention math) with (a) the model's own SDPA output, (b) Hugging Face eager attention evaluated on the identical q/k/v, (c) my own SDPA call on identical inputs with my mask (to test mask/q/k/v/RoPE/GQA exactly), and (d) an **FP32 reference** (projections, q/k norm, RoPE and attention all in fp32 from the same bf16 layer input). Variants of the recompute isolate precision (bf16 cast of attention probabilities, bf16 scores), GQA expansion (explicit per-group loop vs `repeat_kv`), RoPE precision, normalisation precision and reduction order. Report absolute, RMS and maximum errors of the per-head outputs and of the verdict-coordinate contributions, localise the worst cases (example, layer, head, position, token), and give S8-specific numbers at the last position and at all positions.
2. **Independent descriptive source-position analysis using the model's own attention implementation** (`scripts/phase25_source_positions.py`): attention weights come from the model's eager attention (`output_attentions`), values from the model's own `v_proj`, gains from `o_proj`; **the custom recompute path is not used**. Per head and source category (first token/sink, chat prefix, instruction, rule, fact, conclusion, template tail, final prompt tokens, self) report attention mass and signed value-weighted contributions `A_{t,s}·(gain_h·v_s)` per class and their class differences, on alignment-validated valid/invalid pairs (logic) and on class-conditional sets for the localizer and PrOntoQA. The exact accounting identity (sum over sources = head contribution) is verified against the model's own eager head outputs. The symmetric routing/content split of a pair difference may be reported as an **accounting identity only (descriptive, not causal)**. A layer-average profile is shown as a baseline for context only. Eager-vs-SDPA differences of the S8 contributions are reported.
3. **Decision on intervention follow-ups.** A-only/V-only patching is permitted only if the recompute can be validated under a **newly justified criterion that is written into this document and committed before any A-only/V-only result is examined**. If numerical discrepancies remain unexplained or materially affect the S8 heads, no routing/content interventions are run; the descriptive analysis is reported and the phase stops.
4. `docs/reports/phase25_report.md` with findings, validation details, limitations and recommendations. Stop for review.

## Rules
Any intervention run in this phase is explicitly labelled **exploratory** and cannot change the Phase 2 verdict. The new criterion (if any) is stated as Amendment 2 below, after the diagnostic (which contains no intervention effects) and before the first A/V patch.

## Amendment 2 — new validation criterion for the recompute path (written after the diagnostic and the descriptive analysis; BEFORE any A-only / V-only / A+V result exists)
**Basis (diagnostic only, no intervention effects):** `results/phase25/recompute_diagnosis.json`, `rounding_floor.json`. On identical bf16 layer inputs: the model's own SDPA call is reproduced by an independent SDPA call with my mask to rel. L2 1.6–1.8e-4 (so mask, q/k norm, RoPE and GQA expansion are exact; an explicit per-KV-group loop is bit-identical to `repeat_kv`); the fp32-attention recompute differs from the model's output by rel. L2 ≈ 1.8e-3, which is within ≈ 10 % of the pure bf16 *output-quantisation floor* (1.65e-3) — and even that floor has a worst-case verdict-contribution error of 2.1–3.0 % of the all-head std, i.e. the original 2 % worst-case rule lies below what any bf16-output implementation can achieve. HF eager attention differs from SDPA by ≈ 1.3 % (7× more than the recompute). The worst-case errors are 93 % at middle positions, 0 % at the first token, and the model's SDPA output is closer to the FP32 reference in 48 % of them (symmetric rounding noise, not a systematic bias). For the frozen S8 heads the recompute-vs-model contribution error normalised by the head's own std is ≤ 1.6 % at any position and ≤ 0.84 % at the last token.

**The recompute path is accepted for EXPLORATORY A-only / V-only / A+V patching of the frozen S8 heads iff all of the following hold** (V1–V3 are already measured by the diagnostic; V4–V5 are checked inside the patching script, V4 before any A/V effect is computed):
* **V1 (input fidelity).** An independent SDPA call on the recompute's own q/k/v/mask reproduces the model's captured head output with rel. L2 ≤ 1e-3 at every S8 layer.
* **V2 (S8 contribution accuracy).** For each S8 head, recompute vs model SDPA: RMS error ≤ 1 % and maximum error ≤ 2 % of that head's own contribution std, at the last token and at all real positions.
* **V3 (noise-floor referenced).** Layer-level rel. L2 error of the recompute vs the model ≤ 1.25 × the bf16 output-quantisation floor, and the recompute is not farther from the FP32 reference than the model's own SDPA output is (rel. L2 ratio ≤ 1.05).
* **V4 (self-patch noise floor, measured first).** Self-patching (source = target, A+V) of each patched head set on the aligned pairs changes answer margins by ≤ 1.0 logit at maximum and ≤ 0.3 logit on average, and changes the verdict in ≤ 1 % of trials. Effects smaller than 3× the measured floor are not interpreted. If V4 fails the script stops before computing any A/V effect.
* **V5 (consistency with full-`z` patching).** A+V patching of S8 on the aligned pairs (all positions) reproduces the full-`z` patch transfer measured by the model-native hook to within 0.05.

**Interpretation rules fixed in advance (exploratory; cannot change the Phase 2 verdict).** Report margin transfer, flip rate and verdict-coordinate transfer for A-only, V-only, A+V and full-`z`, all positions and last position, on alignment-validated pairs (`num_orig` and `num_rev`), for S8 jointly, L22H5 and L21H19 individually, with random layer-count-matched head sets (n = 10, deterministic recorded seeds) as controls. A and V effects are **not** assumed additive: the interaction `T(AV) − T(A) − T(V)` is reported with a bootstrap CI. Labels: *attention-routing-dominant* if `T(A) ≥ 2·T(V)` and `T(A) ≥ 0.10`; *value/content-dominant* if `T(V) ≥ 2·T(A)` and `T(V) ≥ 0.10`; otherwise *mixed/interactive*. The descriptive accounting split from step 2 is shown next to it and is not itself causal evidence. Budget: ≤ 0.5 GPU-hour.
