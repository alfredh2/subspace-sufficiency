# Phase 5 report: how does verdict-related information become available at the summary positions around layer 19?

Plan: `docs/phase5_plan.md` (committed with the 8 approval amendments before implementation). Tables: `results/phase5/report_tables.md`; mechanical scoring: `results/phase5/criteria_verdict.json`; raw per-trial arrays: `results/phase5/*.npz`; frozen selection: `results/phase5/selection.json`. Phases 0–4 artifacts and verdicts are unchanged. GPU time: about 0.8 h of logged job time, about 1.0 h with model loading and the untimed pilot (soft budget 3–4 h; no extension needed).

## Outcome: **MIXED. None of the three pre-specified hypotheses is supported as stated; the data support a fourth description**
The layer-19 effect is carried by **three heads (L19H10, L19H31, L19H17)** that **copy value content, not attention routing**, into the summary rows. The content comes mainly from the **conclusion line** (conclusion body ≈ half, conclusion-final token ≈ 14%, fact line ≈ 5%) and is **independent of lexical identity**. At the summary rows the three heads write 81% of the source–target verdict-coordinate gap with only a 5–6% relative change of the layer-19 output. The downstream response to that write is convex, and later summary-row processing in layers 20–22 *reduces* rather than amplifies the effect. This does not identify where the conclusion-line value content was computed, and it does not show that layer 19 computes logical validity.

## Validation (all gates passed before any held-out evaluation)
* 5 new unit-test groups (`tests/test_phase5.py`; full suite 120 tests): row-set head patch (identity, exactness, equivalence to the Phase 4 component patch, α interpolation, norm-matched delta), delta-recompute patch (null patch = native z, additivity over key groups, rows outside R and later keys unchanged, AV = native Z), pinning mechanics, integration.
* Regression gate: the all-32-head Z-patch at the summary rows reproduces the Phase 4 layer-19 attention-output patch **bit-exactly** (0.3601 / 0.3897). Recompute acceptance (validation): AV over all keys equals the native Z-patch to 9e-5 in transfer; no layer-19 head exceeds 0.22% relative RMS recompute error (L19H30/31 included); the `Other` key group is an exact no-op; pin verification max difference 0.0; patched-head verification 0.0.

## Stage 1: head localization (selection on 4 validation contents only; evaluation on set A)
* Individual-head causal ranking R1 (validation): H10 (0.129), H31 (0.069), H17 (0.039), H28 (0.019)… The nested top-k curve reaches 0.8 of the all-32 effect at **k\* = 3**; **H\* = {10, 17, 31}** was frozen. On set A, `num_orig` / `num_rev`: all-32 0.36 [0.34, 0.38] / 0.39 [0.37, 0.41]; **H\* 0.35 [0.33, 0.36] / 0.39 [0.37, 0.41] = 97% / 100% of all-32**; L19H10 alone 0.12 / 0.13; single H31 0.06, H17 0.03. KV-group sets: g2 (heads 8–11, contains H10) 0.11, g7 (28–31, contains H31) 0.06, g4 (16–19, contains H17) 0.03, all others ≈ 0.
* The top-k curve is **non-monotone**: the best nested set (k = 21–24) reaches 0.52–0.55, well above all-32 (0.36–0.39), so the remaining heads net *oppose* the transfer.
* Null sets (size 3, 20 draws each; share of all-32): random mean 0.006, max 0.05; output-magnitude-matched mean 0.03, max 0.10; magnitude-equalised (patch scaled by 1.6–2.0×) mean 0.06, max 0.20. H\* are the three largest-output-magnitude layer-19 heads, so no disjoint set can match their summed magnitude; the matched sets have 0.58× the magnitude on average and the equalised variant corrects for this. Norm-matched random-direction patch of H\*: 0.008.
* Causal ranking agrees with the test single-head transfers (Spearman 0.95–0.96); the descriptive local d_c-write ranking R2 (0.31–0.35) and the Phase 2 last-row ranking R3 (0.20) agree only at the top: descriptive attribution and causal influence are not interchangeable beyond the leading heads. The R2 top-3 set coincides with H\*; the R3 top-3 set (H10, H28, H31) gives 0.29 / 0.33.
* Row specificity: H\* at G1 rows 0.10, G2 rows 0.16, non-summary rows 0.07, the query row 0.01, random row sets 0.06.
* **Immediate residual change at index 20 (rows G1∪G2), reported separately from the final effect:** local d_c transfer L_c = 0.81, transfer along the validation-frozen scalar direction w = 0.71 (`num_orig`; `num_rev` 0.81 / 0.70); mean relative norm change of the layer-19 output 5.7–5.8%. Final: T_m 0.35 / 0.39, T_c 0.38.
* **C (concentration): met** in both formats (k\* ≤ 4, share ≥ 0.70 with lower bounds ≥ 0.60, null means/maxima within 0.15 / 0.30 of the all-32 effect).

* **Scalar-sufficiency test (frozen on validation: direction w, dose curve g, all fitted parameters):** per-group errors T_V − ĝ(π_K) are within −0.05…+0.05 for every key group and group set, in both formats (largest +0.05 for Fact+Concl in `num_rev`); the proportional baseline errs by up to 0.06 and the d_c-scalar baseline by up to 0.07. The super-additivity of groups in the answer (singles 0.24 vs joint 0.34) is explained by the convex dose curve, not by complementary content. * Criteria: single-group sufficiency not met (no group has a lower bound ≥ 0.60; Concl is 0.48–0.51 on A, 0.59–0.61 on B); complementarity not met (I_res small; Concl's upper bound is not below 0.50).

## Stage 3: summary-row pinning, local readout, dose-response (H\*)
* **Fraction surviving summary-row pinning `S_pin`** (attention + MLP of layers 20–22 at rows G1∪G2 forced to the clean target values): **1.57 [1.49, 1.65] (`num_orig`), 1.48 [1.41, 1.55] (`num_rev`)**; attention-only 1.40 / 1.35, MLP-only 1.24 / 1.24; pinning layers 20–35 gives the same. G1 rows 0.97 / 1.04, G2 rows 1.77 / 1.71. Pinning *increases* the transferred effect by about 50%: processing at the summary rows in layers 20–22 partly cancels the layer-19 write. `S_pin` is not a direct-write fraction, and a value above 1 means the summary-row recomputation is net opposing, not amplifying. Same direction for all-32 (1.39 / 1.35) and L19H10 alone (1.36 / 1.41). Pinned magnitude-equalised null sets have very small denominators and are not interpretable (reported in the tables).
* **Local ratio** ρ = L_c / T_c = 2.16 / 2.11: at the summary rows the layer-19 write closes 81% of the d_c gap, whereas only 38% of the final-coordinate gap appears at the answer row, so about half of the local write never reaches the answer position's coordinate.
* **Dose-response** (T_m(α)/T_m(1)): 0.13, 0.32, 0.60, 1.43, 1.75 at α = 0.25, 0.5, 0.75, 1.25, 1.5 (`num_rev` 0.13, 0.31, 0.60, 1.40, 1.67); g(0.5)/g(1) = 0.32 [0.30, 0.34] / 0.31, convex by the preregistered threshold (≤ 0.40, upper bound ≤ 0.50). The validation curve used for the scalar model was 0.05, 0.12, 0.22, 0.36, 0.50, 0.61 for α = 0.25…1.5.

## Stage 4: validation of the leading description
* **Reversed answer mapping (`num_rev`):** every number above is within a few hundredths of `num_orig`.
* **Held-out template families** (3 families never used in MVS optimisation; 94 trials vs 340): H\* 0.36 vs 0.34 (`num_orig`), 0.39 vs 0.39 (`num_rev`); V(Concl) 0.15–0.17 vs 0.17–0.21; V(Fact+Concl+G1) 0.35 vs 0.33 and 0.39 vs 0.38.
* **Nonword replication B** (43 contents, 400 trials per format; documented prior exposure in earlier MVS research, not untouched; configuration frozen by file hash before it ran): H\* share of all-32 0.93 / 0.97; S_pin 1.67 / 1.64; ρ 2.24 / 2.22; F_A ≤ 0.02; F_Concl 0.59 / 0.61, F_G1 0.14, F_Fact 0.03–0.05, F(Concl+G1) 0.83 / 0.86, all five groups 0.97–0.98; g(0.5)/g(1) = 0.35 / 0.35; scalar-model errors within ±0.05; nulls as on A (random mean 0.8% of all-32, matched 5%, equalised 11%, max 21%); norm-matched random direction 0.01.
* **Matched lexical controls** (set A, `num_orig`, 708 trials with same-label, different-content sources): H\* flips 3.7% of verdicts (mean |Δmargin| 1.6 logits) versus 0–0.6% for random head sets; within the 0.10 limit.
* **Cross-content control (exploratory, added after the freeze):** target and source have *opposite labels and different contents* (382 aligned trials). H\* transfers 0.35 (99% of the all-head effect), random heads 0.00–0.01; V-patch fractions F: Concl 0.47, G1 0.14, Fact 0.06, Concl+G1 0.72, Fact+Concl+G1 0.96; A-only 0.004. The transported feature does not depend on the lexical identity of the matched sibling.
* **Controls (V4):** random/matched heads, lexical flip and norm-matched noise pass. **Two preregistered control inequalities fail:** random row sets for H\* (0.06 against a limit of 0.054 = 0.15 × the all-32 effect) and random key groups (see Stage 2: the pool overlaps the conclusion body).

## Hypothesis scoring (non-exclusive; mechanical)
| hypothesis | primary condition | status |
|---|---|---|
| H1 transport (existing content moved into the summary rows) | one source group with lower bound F ≥ 0.60 and F_A ≤ 0.20 | not supported as stated: F_A holds, but the content is spread over Concl (0.5), G1 (0.14) and Fact (0.05), additive after the convex response |
| H2 combination (complementary groups) | no single group upper bound ≥ 0.50, a group set ≥ 0.75, I_res ≥ 0.15 | not supported (I_res 0.03–0.05) |
| H3 amplification at the summary rows | `S_pin` ≤ 0.30, ρ ≤ 0.25, scalar fit, convex dose | not supported (`S_pin` 1.5–1.7, ρ ≈ 2.1; scalar fit and convex dose hold) |
Mixture actually observed: content-independent value transport from the conclusion line by H10/H31/H17, a convex downstream response, and net attenuation by later summary-row processing (`1 − S_pin` is negative, −0.57 / −0.48).

## What the evidence does and does not show
* Shown: where and from which positions the layer-19 head output gets its transferable content; that attention weights do not matter; that the content is not tied to the matched sibling's words; that the summary-row layer-19 write is nearly a full verdict-coordinate write locally and is partly cancelled by layers 20–22 at the same rows; consistency across formats, held-out families and the nonword set.
* Not shown: that the verdict feature in the conclusion-line value vectors was computed before layer 19 rather than by it (the cross-content control makes a purely lexical source unlikely, but the vectors are products of earlier layers that were not traced); that layer 19 or any layer computes logical validity; that the three heads are necessary (other routes can exist); that the one-dimensional scalar model is the true mechanism; any verdict selectivity (not tested). The onset of causal transfer is a property of patching sufficiency, not a time of computation.

## Deviations and disclosures
1. **Magnitude-matched null revised before the held-out evaluation.** The first selection run found no disjoint head set whose summed output magnitude is within 10% of H\* (H\* are the three largest-magnitude heads). I replaced the sum-matching rule by per-head magnitude strata (nearest-6 neighbours) and added a magnitude-equalised variant; the reported selection is the second run, committed before any set-A evaluation.
2. The pilot stage time was under-logged (about 40 s recorded, about 5 min actual); budget totals above are corrected in the prose.
3. After seeing the Stage 1–3 outputs I changed the report code to include all key groups (including Rule and Other) in the scalar-fit criterion (the plan says every group); no result or threshold changed. The frozen dose-response model has a constant-extrapolation floor at π ≈ 0 (error −0.05); it was not altered.
4. The cross-content control, the held-out-family breakdown and `code` additions to `pipeline.py`/`phase5_run.py` were added after the freeze, so the current files no longer match `frozen_config.json`; Replication B ran under the frozen hashes. The exploratory control is outside the criteria.
5. Not run: the planned exploratory mismatched-content hybrid (3d), as the cross-content control addressed the lexical-identity question at lower cost; a per-layer pinning breakdown (which of layers 20, 21, 22 cancels the write) is a natural follow-up but would extend the scope.
6. Two preregistered control inequalities fail (random rows, random keys), reported above.
