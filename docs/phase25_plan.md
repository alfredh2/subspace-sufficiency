# Phase 2.5 amendment — source positions and routing/content (narrowly scoped)

**Status of Phase 2.** Preserved unchanged: the preregistered Phase 2 verdict is **mixed / inconclusive**; the original attention-recompute gate is recorded as **FAILED** (worst-case d_c-contribution error 2.7 % / 2.4 % of std at layers 19 / 22 vs the 2 % limit); no Phase 2 threshold or criterion is altered. The frozen S8 selection (L22H5, L21H19, L20H8, L22H8, L22H15, L19H10, L22H6, L22H4) is not changed; no additional heads are searched. No checkpoint, dataset or earlier result is modified. Outputs go to `results/phase25/`. Nothing is pushed; no co-author trailers.

## Procedure (in this order)
1. **Diagnose the worst-case recompute errors** (`scripts/phase25_diagnose_recompute.py`). On real padded Qwen3-8B batches, for layers 0, 10 and the S8 layers 19–22: compare the custom recompute (fp32 attention math) with (a) the model's own SDPA output, (b) Hugging Face eager attention evaluated on the identical q/k/v, (c) my own SDPA call on identical inputs with my mask (to test mask/q/k/v/RoPE/GQA exactly), and (d) an **FP32 reference** (projections, q/k norm, RoPE and attention all in fp32 from the same bf16 layer input). Variants of the recompute isolate precision (bf16 cast of attention probabilities, bf16 scores), GQA expansion (explicit per-group loop vs `repeat_kv`), RoPE precision, normalisation precision and reduction order. Report absolute, RMS and maximum errors of the per-head outputs and of the verdict-coordinate contributions, localise the worst cases (example, layer, head, position, token), and give S8-specific numbers at the last position and at all positions.
2. **Independent descriptive source-position analysis using the model's own attention implementation** (`scripts/phase25_source_positions.py`): attention weights come from the model's eager attention (`output_attentions`), values from the model's own `v_proj`, gains from `o_proj`; **the custom recompute path is not used**. Per head and source category (first token/sink, chat prefix, instruction, rule, fact, conclusion, template tail, final prompt tokens, self) report attention mass and signed value-weighted contributions `A_{t,s}·(gain_h·v_s)` per class and their class differences, on alignment-validated valid/invalid pairs (logic) and on class-conditional sets for the localizer and PrOntoQA. The exact accounting identity (sum over sources = head contribution) is verified against the model's own eager head outputs. The symmetric routing/content split of a pair difference may be reported as an **accounting identity only (descriptive, not causal)**. A layer-average profile is shown as a baseline for context only. Eager-vs-SDPA differences of the S8 contributions are reported.
3. **Decision on intervention follow-ups.** A-only/V-only patching is permitted only if the recompute can be validated under a **newly justified criterion that is written into this document and committed before any A-only/V-only result is examined**. If numerical discrepancies remain unexplained or materially affect the S8 heads, no routing/content interventions are run; the descriptive analysis is reported and the phase stops.
4. `docs/phase25_report.md` with findings, validation details, limitations and recommendations. Stop for review.

## Rules
Any intervention run in this phase is explicitly labelled **exploratory** and cannot change the Phase 2 verdict. The new criterion (if any) is stated as Amendment 2 below, after the diagnostic (which contains no intervention effects) and before the first A/V patch.
